矯正 / 治療・保定

保定

保定とは

保定 retentionとは、動的治療によって目的の位置に移動させた歯および顎骨を、その位置と状態で長期間保持し、安定できる条件を整える処置。

矯正治療は「後戻り」というリスクを背負っており、動かすことよりも動かした位置に維持しておくことのほうがむずかしいといわれる。

保定の種類

種類 説明 適応
自然的保定 保定装置を用いず自然の力で保持 1本だけの反対咬合など
機能的異常を除去した場合
器械的保定 保定装置を用いて保持 一般的な矯正治療後
永久保定 補綴装置で永久的に固定 後戻りが強く予想される場合
ブリッジ、インレーなど

自然的保定が成立する条件

  • 口腔周囲筋が正常な機能力となり咬合を安定させる
  • 正しい前歯被蓋や咬頭嵌合が保定力となる
  • 歯の支持組織が新しい環境に適応する

固定式保定装置

装置 特徴
犬歯間保定装置 下顎に多用

ボンデッドリテーナー ツイストワイヤーを歯に直接接着
保定効果が高いが口腔清掃に注意
可撤式 vs 固定式
  • 可撤式：清掃容易、患者の協力が必要
  • 固定式：協力に依存しない、清掃困難

保定期間

保定期間の決定に影響する因子：不正咬合の原因・種類・程度、動的治療期間、治療方法、治療終了時の咬合状態、支持組織の状態など。

  • 6か月〜1年
  • 治療期間の約半分
  • 治療期間と同じ期間
  • 5年経過で終了
  • ほぼ永久的に使用

※様々な考え方があり、一律には決定できない

再発の原因

  • 患者の協力不足：保定装置の装着が不十分
  • 保定期間の不足
  • 保定方法の不適当
  • 不正咬合の原因が残存：口腔習癖など
  • 咬合調整の不足
  • 診断の誤り

再発防止策【頻出】

防止策 説明
長期保定 保定装置を確実に長期間装着させる
オーバーコレクション 過度の治療を行い、後戻りで正常咬合に
過蓋咬合、開咬などに適用
早期治療 顎の成長発育が旺盛な時期に治療
永久保定 ブリッジ、インレーで補綴的に保定
口腔習癖の除去 動的治療中〜保定期間を通じて除去

過去問

103C99

矯正治療後の再発防止に有効なのはどれか。すべて選べ。

a 長期保定
b 咬合調整
c セプトトミー
d 口腔習癖の除去
e オーバーコレクション
正解：a, b, c, d, e

【解説】再発防止策として、長期保定（保定装置の継続使用）、咬合調整（咬頭嵌合の改善）、セプトトミィ（捻転歯の後戻り防止）、口腔習癖の除去（原因除去）、オーバーコレクション（過度の治療で後戻りを見込む）が有効。すべて正解。

104D44

20歳の女性。上下顎前歯の突出を主訴として来院した。診断の結果、上下顎第一小臼歯を抜去し、ヘッドギアを併用してマルチブラケット治療を行った。治療後、上顎犬歯間幅径は1mm増加し、上顎第一大臼歯間幅径は1mm減少した。動的治療後に上顎に用いる保定装置で適切なのはどれか。1つ選べ。

a リンガルアーチ
b 犬歯間保定装置
c スプリングリテーナー
d Beggタイプリテーナー
e トランスパラタルアーチ
正解：d

【解説】犬歯間幅径が増加している場合、後戻り防止のため犬歯部をカバーする保定装置が必要。Beggタイプリテーナーは唇側線が犬歯から最後方臼歯まで覆う可撤式保定装置で適切。犬歯間保定装置は固定式で下顎に多用。

出題パターンの整理
  • 再発防止策 → 長期保定、咬合調整、セプトトミィ、口腔習癖の除去、オーバーコレクション（すべて有効）
  • セプトトミィ → 捻転歯の後戻り防止
  • オーバーコレクション → 過蓋咬合、開咬に適用
  • 犬歯間幅径増加 → Beggタイプリテーナーで保定
  • 可撤式：Hawley、Begg、トゥースポジショナー
  • 固定式：犬歯間保定装置、ボンデッドリテーナー
