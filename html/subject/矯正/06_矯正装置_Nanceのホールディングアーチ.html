矯正 / 矯正装置

Nanceのホールディングアーチ

装置の概要

Nanceのホールディングアーチ（Nance Holding Arch）は、上顎第一大臼歯にバンドを装着し、口蓋前方部にレジンボタン（アクリリックボタン）を設けた固定式矯正装置。

基本構造

構成要素 役割
バンド 上顎第一大臼歯に装着
主線（パラタルバー） 左右のバンドを連結
レジンボタン 口蓋前方の粘膜に接触し、大臼歯の近心移動を防止

装置の特徴【頻出】

Nanceのホールディングアーチの特徴
  • 歯列弓周長の保持に適している（最重要）
  • 上顎大臼歯の近心移動を防止
  • 加強固定として使用
  • 固定式装置（患者による調整不要）
  • 金属を使用（金属アレルギーに注意）

できないこと

  • 咀嚼機能の回復 → 補綴装置ではない
  • 口腔清掃時の着脱 → 固定式装置
  • 定期的な活性化 → 保持が目的（拡大ネジなし）
  • 対合歯の挺出防止 → 対合には作用しない

加強固定【頻出】

加強固定（Reinforced anchorage）とは、固定源の抵抗を増大させて、反作用による固定歯の移動を最小限にする方法。

加強固定に用いる装置
  • ヘッドギア：顎外固定で最も強力
  • Nanceのホールディングアーチ：口蓋粘膜を固定源に追加
  • リップバンパー：口唇圧を利用
  • トランスパラタルアーチ：左右大臼歯を連結
  • 矯正用アンカースクリュー：骨に埋入

加強固定に含まれない装置

  • チンキャップ → 顎整形装置（下顎の成長抑制）
  • バイオネーター → 機能的矯正装置
  • アクチバトール → 機能的矯正装置

類似装置との比較

装置 特徴 主な用途
Nanceのホールディングアーチ レジンボタンが口蓋粘膜に接触 歯列弓周長の保持、加強固定
トランスパラタルアーチ 左右大臼歯を連結（粘膜非接触） 大臼歯の回転防止、固定
リンガルアーチ 舌側に主線が走行 前歯の移動、被蓋改善

過去問

110C118

Nanceのホールディングアーチの特徴はどれか。1つ選べ。

a 咀嚼機能が回復できる。
b 口腔清掃時に着脱できる。
c 定期的な活性化を要する。
d 対合歯の挺出を防止できる。
e 歯列弓周長の保持に適している。
正解：e

【解説】Nanceのホールディングアーチは歯列弓周長の保持が主目的。レジンボタンが口蓋粘膜に接触し、大臼歯の近心移動を防止する。固定式なので着脱不可、矯正装置なので咀嚼機能回復はできない。

108A70

加強固定として用いられるのはどれか。すべて選べ。

a ヘッドギア
b チンキャップ
c バイオネーター
d リップバンパー
e Nanceのホールディングアーチ
正解：a, d, e

【解説】加強固定に用いる装置は、ヘッドギア（顎外固定）、リップバンパー（口唇圧利用）、Nanceのホールディングアーチ（口蓋粘膜を固定源に追加）。チンキャップは顎整形装置、バイオネーターは機能的矯正装置で、いずれも加強固定ではない。

103C97

上下顎第一小臼歯を抜去してマルチブラケット治療を行うこととした。上顎大臼歯が近心に移動するのはどれか。1つ選べ。

a II級ゴム
b III級ゴム
c ヘッドギア
d リップバンパー
e Nanceのホールディングアーチ
正解：b

【解説】III級ゴムは上顎を後方、下顎を前方に牽引するため、上顎大臼歯は近心移動する。他の選択肢は大臼歯の固定または遠心移動に用いる。
a：II級ゴムは上顎を前方牽引
c：ヘッドギアは大臼歯を遠心移動
d, e：加強固定として大臼歯の移動を防止

104A102

金属アレルギーを有する患者に使用する際に注意を要するのはどれか。すべて選べ。

a ヘッドギア
b リップバンパー
c トゥースポジショナー
d Hawleyタイプリテーナー
e Nanceのホールディングアーチ
正解：a, b, d, e

【解説】金属を使用する装置は金属アレルギーに注意が必要。ヘッドギア、リップバンパー、Hawleyタイプリテーナー（ワイヤー使用）、Nanceのホールディングアーチが該当。トゥースポジショナーはシリコーンゴム製で金属を使用しない。

出題パターンの整理
  • 主目的：歯列弓周長の保持
  • 加強固定：ヘッドギア、リップバンパー、Nanceのホールディングアーチ
  • 大臼歯の近心移動防止：抜歯矯正時の固定源
  • 金属アレルギー：注意が必要（金属使用）
  • 患者調整不要：固定式で歯科医師が管理
