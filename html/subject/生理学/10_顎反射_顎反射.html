顎反射

I. 三叉神経感覚核群

感覚 一次ニューロン 入力先 関与する反射
触・圧覚 三叉神経節 三叉神経主感覚核、三叉神経脊髄路核（吻側・中位亜核） 持続性歯根膜咬筋反射
痛覚 三叉神経節 三叉神経脊髄路核（尾側亜核） 開口反射
温度覚 三叉神経節 三叉神経脊髄路核（尾側亜核） －
固有感覚 三叉神経中脳路核 三叉神経運動核 下顎張反射、一過性歯根膜咬筋反射
三叉神経中脳路核の特徴
  • 歯根膜と咀嚼筋筋紡錘からの固有感覚を伝える
  • 一次ニューロンの細胞体が脳幹内にある（例外的）
  • 下顎張反射、一過性歯根膜咬筋反射に関与

II. 下顎反射の種類と役割

反射 役割 現れる運動
下顎張反射 顎位を常に一定に保つ。下顎が下がった場合、顎を挙上させて閉口 閉口筋の緊張増加
開口した場合は閉口運動
脱負荷反射 硬いものを噛み砕いた瞬間に脱力して、上下歯の衝突・口腔内損傷を避ける 強い閉口運動中に閉口運動を停止
開口反射 口腔内・周辺に侵害刺激が加わったときに、有害な刺激から逃れ、口腔を防御 開口筋収縮 + 閉口筋弛緩
→ 開口運動
歯根膜咬筋反射 咬合・咀嚼時に咬合力・咀嚼力を調節。食物の固さに応じた咀嚼の調節 閉口筋の収縮力増強
閉口運動の強度増大

III. 下顎反射の反射弓【重要】

1. 下顎張反射（伸張反射）

項目 内容
誘発刺激 下顎を開口させる方向に働く力（閉口筋の受動的伸張）
受容器 筋紡錘（閉口筋内）
求心路 Ia群線維
中枢 三叉神経中脳路核
遠心路 Aα線維（α運動ニューロン）
効果器 閉口筋（収縮）
シナプス数 単シナプス反射

※膝蓋腱反射と同じ反射機構（伸張反射）

2. 開口反射

項目 内容
誘発刺激 三叉神経支配領域（特に口腔周辺）への侵害刺激、強い機械刺激
受容器 侵害受容器（自由神経終末）
求心路 主にAδ線維
中枢 三叉神経節 → 三叉神経脊髄路核
遠心路 興奮性介在ニューロン → α運動ニューロン → 開口筋（収縮）
抑制性介在ニューロン → 三叉神経上核 → 閉口筋（弛緩）
シナプス数 多シナプス反射

3. 一過性歯根膜咬筋反射

項目 内容
誘発刺激 歯を叩くなど一過性の歯への刺激
受容器 歯根膜機械受容器（固有受容器）
中枢 三叉神経中脳路核
シナプス数 単シナプス反射

4. 持続性歯根膜咬筋反射

項目 内容
誘発刺激 歯への持続性の触圧刺激
受容器 歯根膜機械受容器
求心路 Aβ線維
中枢 三叉神経節 → 三叉神経主感覚核
シナプス数 多シナプス反射

IV. 反射の比較まとめ

反射 受容器 中枢 シナプス
下顎張反射 筋紡錘 三叉神経中脳路核 単シナプス
脱負荷反射 筋紡錘 三叉神経中脳路核 単シナプス
開口反射 侵害受容器 三叉神経脊髄路核 多シナプス
一過性歯根膜咬筋反射 歯根膜（固有受容器） 三叉神経中脳路核 単シナプス
持続性歯根膜咬筋反射 歯根膜 三叉神経主感覚核 多シナプス
単シナプス反射 vs 多シナプス反射
  • 単シナプス反射：介在ニューロンを介さない。反応が速い（伸張反射など）
  • 多シナプス反射：介在ニューロンを介する。複雑な調節が可能
  • 三叉神経中脳路核経由の反射は単シナプス反射

V. 過去問で確認

110C74

骨格筋、筋紡錘およびその神経支配の模式図を示す。
アとイのニューロン活動によって生じるのはどれか。2つ選べ。

a 開口反射
b 屈曲反射
c 下顎張反射
d 膝蓋腱反射
e 折りたたみナイフ反射
正解：c, d

【解説】問題文の「ア」はIa群線維（筋紡錘からの求心性線維）、「イ」はα運動ニューロン（遠心性線維）を示している。

  • これは伸張反射（単シナプス反射）の回路である
  • c ○ 下顎張反射：咀嚼筋筋紡錘 → Ia群線維 → 三叉神経中脳路核 → α運動ニューロン → 閉口筋
  • d ○ 膝蓋腱反射：大腿四頭筋筋紡錘 → Ia群線維 → 脊髄 → α運動ニューロン → 大腿四頭筋
  • a × 開口反射：侵害受容器（自由神経終末）からの多シナプス反射
  • b × 屈曲反射：侵害刺激による多シナプス反射
  • e × 折りたたみナイフ反射：腱紡錘（Golgi腱器官）からのIb抑制
