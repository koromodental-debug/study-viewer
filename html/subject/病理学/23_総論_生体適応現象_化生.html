病理学 / 総論

生体適応現象：化生

I. 化生の定義

項目 内容
定義 すでに形成を終えた細胞が、他の種類の細胞に変化すること
位置づけ 再生の一様式と考えられている
発生部位 上皮細胞間、または間葉系細胞間で生じる
原因 慢性炎症刺激、機械的刺激、環境変化など
化生のポイント
  • 化生は可逆的な変化（刺激が除去されれば元に戻りうる）
  • 上皮細胞は上皮細胞に、間葉系細胞は間葉系細胞に変化（系統は超えない）
  • 持続的な刺激に対する適応現象

II. 化生の種類

上皮性化生

種類 変化 例
扁平上皮化生 円柱上皮・腺上皮 → 扁平上皮 唾石に接する導管、気管支、子宮頸部
腸上皮化生 胃腺上皮 → 小腸上皮 慢性胃炎（前癌病変）
アポクリン化生 腺上皮 → アポクリン汗腺様 乳腺
オンコサイト化生 腺上皮 → 好酸性顆粒状細胞質 唾液腺（加齢変化）

間葉系細胞化生

種類 変化 例
骨化生 線維芽細胞 → 骨芽細胞 骨化性筋炎
軟骨化生 線維芽細胞 → 軟骨細胞 多形腺腫
脂肪化生 線維芽細胞 → 脂肪細胞 －

III. 口腔領域での化生

部位・疾患 化生の種類 原因
唾石に接する導管 扁平上皮化生 機械的刺激（唾石による慢性刺激）
唾液腺（加齢） オンコサイト化生 加齢変化
多形腺腫 軟骨化生、骨化生 腫瘍内での分化

IV. 生体適応現象の比較

現象 定義 例
萎縮 細胞・組織の縮小 廃用性萎縮、老人性萎縮
肥大 細胞の容積増大 → 臓器の増大 心肥大、骨格筋肥大
過形成（増生） 細胞数の増加 → 臓器の増大 歯肉増殖症、セメント質過形成
化生 細胞の種類が変化 扁平上皮化生、腸上皮化生

V. 過去問

116C15

唾石に接する導管でみられる変化はどれか。1つ選べ。

a 軟骨化生
b 粘液化生
c 扁平上皮化生
d アポクリン化生
e オンコサイト化生
正解：c

【解説】唾石による慢性的な機械的刺激により、導管上皮に扁平上皮化生が生じる。

108A101

矢印で示すのはどれか。1つ選べ。

a 骨化生
b 軟骨化生
c 腸上皮化生
d 扁平上皮化生
e アポクリン化生
正解：d

【解説】画像問題。円柱上皮が扁平上皮に置き換わっている所見 → 扁平上皮化生。
