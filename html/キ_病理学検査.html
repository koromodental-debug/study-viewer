キ. 病理学検査

必修10 検査・臨床判断の基本

染色法 出題27件

【H-E染色（基本染色）】

染色液染まる組織色
ヘマトキシリン好塩基性（核、リンパ球、石灰化物、軟骨）紫青色
エオシン好酸性（細胞質、結合組織、赤血球、アミロイド）ピンク色

【特殊染色】

染色法染まる対象色
PAS染色多糖類（グリコーゲン、粘液）赤紫色
Grocott染色真菌黒色
Congo-Red染色アミロイド赤褐色（偏光で黄緑）
Ziehl-Neelsen染色抗酸菌（結核菌など）赤色
Mucicarmine染色粘液赤色
鍍銀染色細網線維、神経線維黒色
No.25

H-E染色で好塩基性に染まるのはどれか。1つ選べ。

a: 核　b: 細胞質　c: 基底膜　d: 膠原線維　e: 弾性線維

正解: a（ヘマトキシリンは核を紫青色に染める）
105A-29

粘液の染色に用いるのはどれか。1つ選べ。

a: PAS染色　b: Grocott染色　c: Congo-Red染色　d: Mucicarmine染色　e: Ziehl-Neelsen染色

正解: d（Mucicarmine染色は粘液を赤く染める。PASも多糖類を染める）

a. 細胞診 出題4件

項目内容
擦過細胞診病変部を擦過して細胞を採取
穿刺吸引細胞診腫瘤に針を刺して細胞を吸引（唾液腺腫瘍に有用）
Papanicolaou染色細胞診の標準染色
Papanicolaouクラス分類意味
Class I正常
Class II異常細胞あるが良性
Class III悪性疑い（要精査）
Class IV悪性強く疑う
Class V悪性
111B-16

穿刺吸引細胞診で診断可能なのはどれか。1つ選べ。

a: 血管腫　b: 脂肪腫　c: 唾液腺腫瘍　d: 神経鞘腫　e: リンパ管腫

正解: c（唾液腺腫瘍は穿刺吸引細胞診で診断可能）

b. 組織診 出題6件

項目内容
ホルマリン固定濃度：10%中性緩衝ホルマリン
パラフィン包埋通常の組織標本作製（数日かかる）
凍結切片術中迅速診断に使用（15〜20分）
生検（バイオプシー）組織の一部を採取して診断
102A-13

病理組織検体を固定する際のホルマリン濃度はどれか。1つ選べ。

a: 1%　b: 5%　c: 10%　d: 50%　e: 100%

正解: c（10%中性緩衝ホルマリンが標準）

悪性腫瘍の病理 出題3件

所見意味
細胞異型核の大小不同、核形不整（悪性を疑うが確定ではない）
構造異型組織構造の乱れ
核分裂像細胞分裂の増加
局所侵襲性（浸潤）基底膜を破って浸潤＝浸潤癌の確定所見
分類基底膜特徴
上皮内癌破られていない上皮内に留まる
浸潤癌破られている基底膜を越えて浸潤
105A-20

浸潤癌と上皮内癌との鑑別で重要な病理所見はどれか。1つ選べ。

a: 細胞異型　b: 構造異型　c: 核分裂像　d: 局所侵襲性　e: 基底膜

正解: d（局所侵襲性＝基底膜を破って浸潤しているかが鑑別点）
まとめ（頻出順）
  • 染色法（27件）＝H-E（核＝紫青色）、PAS（多糖類＝赤紫）、Grocott（真菌）
