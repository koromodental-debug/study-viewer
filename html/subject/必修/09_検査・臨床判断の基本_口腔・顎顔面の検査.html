必修 / 検査・臨床判断の基本

口腔・顎顔面の検査

1. 齲蝕検査

レーザー蛍光強度測定（DIAGNOdent）

波長655nmの半導体レーザーを用いて齲蝕を検出する。歯質の蛍光強度の変化を測定し、齲蝕の程度を数値化する。

特徴
  • 小窩裂溝初期齲蝕の検出に有効
  • 象牙質齲蝕の客観的評価が可能
  • 非侵襲的で再現性が高い
116B16

レーザー齲蝕診断装置に使用されるレーザーの波長はどれか。1つ選べ。

a 455nm
b 655nm
c 1.064μm
d 2.94μm
e 10.6μm
正解：b

【解説】DIAGNOdentは波長655nmの半導体レーザーを使用する。1.064μmはNd:YAGレーザー、2.94μmはEr:YAGレーザー、10.6μmはCO2レーザーの波長。

115A3

象牙質齲蝕の客観的評価に有効なのはどれか。1つ選べ。

a 打　診
b 温度診
c 透照診
d 歯髄電気診
e レーザー蛍光強度測定
正解：e

【解説】レーザー蛍光強度測定は齲蝕の程度を数値で客観的に評価できる。打診・温度診・歯髄電気診は歯髄の状態を評価する検査。透照診は隣接面齲蝕や亀裂の検出に有効。

112D17

小窩裂溝初期齲蝕の検査に用いるのはどれか。1つ選べ。

a 有鉤探針
b 半導体レーザー
c 加熱ストッピング
d エチルクロライドスプレー
e アシッドレッドプロピレングリコール液
正解：b

【解説】小窩裂溝初期齲蝕には半導体レーザー（DIAGNOdent）が有効。有鉤探針での探査は初期齲蝕を破壊する恐れがあるため推奨されない。アシッドレッドは齲蝕象牙質の染色に用いる。

ICDAS（International Caries Detection and Assessment System）

齲蝕の検出と活動性の評価に基づく国際的な診断基準。視診により齲蝕をコード0〜6で分類する。

113B7

齲蝕の検出と活動性の評価に基づく診断基準はどれか。1つ選べ。

a CFI
b OHI
c RCI
d DMF
e ICDAS
正解：e

【解説】ICDASは齲蝕の検出と活動性評価の診断基準。CFIは地域フッ素症指数、OHIは口腔清掃状態指数、RCIは根面齲蝕指数、DMFは齲蝕経験指数。

齲蝕検知液（アシッドレッド）

1%アシッドレッドをプロピレングリコールに溶解した染色液。齲蝕象牙質を染色し、切削範囲の指標とする。

染色される層
  • 寡菌層（外層）：濃染される → 除去すべき層
  • 混濁層（内層）：淡染 → 保存可能
110C7

アシッドレッドに濃染される象牙質はどれか。1つ選べ。

a 寡菌層
b 混濁層
c 正常層
d 透明層
e 生活反応層
正解：a

【解説】齲蝕象牙質の外層（寡菌層）は細菌感染があり再石灰化不能のため、アシッドレッドに濃染される。内層（混濁層）は淡染され、再石灰化可能なため保存する。

2. 透照診

光を歯に透過させて病変を検出する検査法。隣接面齲蝕や亀裂の検出に有効。

111A4

透照診で検出できるのはどれか。1つ選べ。

a 隣接面齲蝕
b 歯根外部吸収
c 象牙質形成不全
d 歯冠部歯髄の形態
e 修復象牙質の形成
正解：a

【解説】透照診は光の透過性の違いを利用して病変を検出する。隣接面齲蝕や亀裂は光の透過性が低下するため検出できる。歯根外部吸収や歯髄形態はエックス線検査で評価する。

107C30

歯の硬組織疾患と検査法との組合せで正しいのはどれか。1つ選べ。

a 亀　裂 ―――――――― 透照診
b 変　色 ―――――――― インピーダンス測定検査
c 酸蝕症 ―――――――― レーザー蛍光強度測定
d 象牙質知覚過敏症 ――― 切削診
e アブフラクション ――― 麻酔診
正解：a

【解説】亀裂は透照診で検出する。インピーダンス測定は齲蝕検査、レーザー蛍光強度測定も齲蝕検査に用いる。

3. 歯髄電気診

歯髄の生死を電気刺激で判定する検査。対照歯と比較して診査することが重要。

110A16

歯の検査で対照歯と比較するのはどれか。1つ選べ。

a 麻酔診
b 楔応力検査
c 歯髄電気診
d 動揺度検査
e 歯周ポケット検査
正解：c

【解説】歯髄電気診は個人差があるため、健全な対照歯と比較して反応閾値の違いを評価する必要がある。

4. 咀嚼能力検査

咀嚼機能を評価する検査。直接的・客観的な指標としてグルコース溶出量を用いる。

検査法の種類

検査法指標特徴
グルコース含有グミグルコース溶出量直接的・客観的
咬合力検査咬合力（N）義歯の支持機能に影響
食品摂取票主観的評価間接的
111C8

咀嚼能力評価において、直接的かつ客観的な指標として用いられるのはどれか。1つ選べ。

a 下顎運動路
b 食品摂取票
c 唾液分泌量
d 咀嚼筋筋電図
e グルコース溶出量
正解：e

【解説】グルコース含有グミを咀嚼し、溶出したグルコース量を測定する方法が直接的・客観的評価法。食品摂取票は主観的評価。

114D13

義歯の支持機能に影響を受けるのはどれか。1つ選べ。

a 舌圧検査
b 咬合力検査
c 発語明瞭度検査
d パラトグラム検査
e ブローイング検査
正解：b

【解説】咬合力検査は義歯の支持機能（顎堤の状態、適合など）の影響を受ける。舌圧検査は舌の筋力評価。

115B10

ある検査の質問項目を図に示す。
この検査はどれか。1つ選べ。

a MMSE
b HDS-R
c GOHAI
d EAT-10

【解説】EAT-10は嚥下障害のスクリーニング用質問票（10項目）。MMSEとHDS-Rは認知機能検査、GOHAIは口腔関連QOL評価。

112A5

濾紙ディスク法による味覚検査で塩酸キニーネを用いて評価するのはどれか。1つ選べ。

a 塩　味
b 甘　味
c 酸　味
d 苦　味
e うま味
正解：d

【解説】塩酸キニーネは苦味の検査に用いる。キニーネはキナ皮から得られるアルカロイドで、強い苦味を持つ。

7. 口臭検査

検査法の比較

検査法特徴
官能検査検査者が直接嗅ぐ、多様な臭気に対応可能
ガスクロマトグラフィー再現性が高い、VSC（揮発性硫黄化合物）を分離定量
半導体ガスセンサー簡便、スクリーニング向き
116A15

口臭検査で、官能検査と比較したガスクロマトグラフィー検査の特徴はどれか。1つ選べ。

a 実施が簡便である。
b 結果の再現性が高い。
c 多様な有臭成分へ対応できる。
d この検査結果単独で診断できる。
e 患者の直前の飲食に左右されやすい。
正解：b

【解説】ガスクロマトグラフィーは機械的測定のため再現性が高い。官能検査は多様な有臭成分に対応できるが、検査者の主観が入る。

8. インピーダンス測定検査

歯の電気抵抗を測定し、齲蝕の深達度を評価する。

測定値と判定

電気抵抗値判定
15kΩ以下齲蝕象牙質（要切削）
15.1〜250kΩ象牙質齲蝕
251〜599kΩエナメル質齲蝕
600kΩ以上健全

9. 歯周ポケット検査

109A29

垂直性歯根破折が疑われる下顎右側第一大臼歯のエックス線写真（別冊No.2）を別に示す。
診断に有用なのはどれか。1つ選べ。

a 温度診
b 透照診
c 咬合音検査
d 楔応力検査
e 歯周ポケット検査
正解：e

【解説】垂直性歯根破折では破折線に沿って深い歯周ポケットが形成される。限局した深いポケットの存在は歯根破折を示唆する重要な所見。

まとめ：検査法と適応
  • 小窩裂溝初期齲蝕 → レーザー蛍光強度測定（655nm）
  • 隣接面齲蝕・亀裂 → 透照診
  • 齲蝕象牙質の範囲 → 齲蝕検知液（アシッドレッド）
  • 歯髄の生死 → 歯髄電気診（対照歯と比較）
  • 咀嚼能力 → グルコース溶出量
  • 嚥下スクリーニング → EAT-10
  • 味覚（苦味） → 塩酸キニーネ
  • 口臭（客観的） → ガスクロマトグラフィー
