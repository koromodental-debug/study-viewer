口腔衛生 / 口腔環境と予防

栄養療法

出題の核
  • 経口摂取が静脈栄養より優れている点 → 腸管免疫能の維持
  • 栄養投与経路の選択順序を理解する
  • 長期経管栄養 → 胃瘻・腸瘻

栄養療法の大原則

"When the gut works, use it!"

腸が働いているなら、腸を使え！

→ 可能な限り経腸栄養（経口・経管）を選択する

栄養投与経路の分類

分類 種類 適応
経腸栄養
（EN）		 経口栄養 嚥下機能が保たれている
経鼻経管栄養 短期間（4週未満）
胃瘻・腸瘻 長期間（4週以上）
静脈栄養
（PN）		 末梢静脈栄養（PPN） 短期間（2週未満）
中心静脈栄養（TPN） 長期間（2週以上）

栄養投与経路の選択フローチャート

① 腸管は機能しているか？

　├ YES → 経腸栄養へ

　└ NO → 静脈栄養（PPN or TPN）


② 経口摂取は可能か？

　├ YES → 経口栄養

　└ NO → 経管栄養へ


③ 経管栄養の期間は？

　├ 短期（4週未満） → 経鼻経管栄養

　└ 長期（4週以上） → 胃瘻・腸瘻

経腸栄養 vs 静脈栄養

経腸栄養の利点

利点 説明
腸管免疫能の維持 消化管には免疫細胞の50〜80%が存在
腸管粘膜の維持 絶食による粘膜萎縮を防止
Bacterial translocation回避 腸内細菌の血中移行を防止
感染リスク低下 カテーテル関連血流感染がない
生理的 消化管ホルモン分泌、腸蠕動維持
低コスト 静脈栄養より安価

経腸栄養の禁忌

  • 腸閉塞
  • 汎発性腹膜炎
  • 難治性嘔吐・下痢
  • 腸管虚血
  • 消化管出血（活動性）

過去問

108C79

摂食・嚥下障害患者で経静脈栄養に比べて経口摂取が優れているのはどれか。1つ選べ。

a 脱水防止
b 尿量の維持
c 血圧の調整
d 電解質の補正
e 腸管免疫能の維持
正解：e

【解説】経口摂取（経腸栄養）が経静脈栄養より優れている点は腸管免疫能の維持。消化管には全身の免疫細胞の50〜80%が存在し、腸管を使うことで免疫能が維持される。脱水防止、尿量維持、血圧調整、電解質補正は静脈栄養でも可能。

113A25

栄養投与経路を選択する際のフローチャートを示す。
ウはどれか。1つ選べ。

a 経口栄養
b 胃・腸瘻栄養
c 経鼻経管栄養
d 中心静脈栄養
e 末梢静脈栄養
正解：b

【解説】フローチャートで「腸管機能あり → 経口摂取不可 → 長期」の場合は胃・腸瘻栄養を選択。4週以上の長期経管栄養では、経鼻チューブによる合併症（鼻腔・咽頭の損傷、誤嚥）を避けるため胃瘻・腸瘻が推奨される。

関連事項

経管栄養患者の口腔ケア

  • 経管栄養中も口腔ケアは毎日実施
  • 経口摂取がなくても口腔内は汚染される（唾液分泌低下、自浄作用低下）
  • 口腔機能低下の予防とリハビリテーション
  • 誤嚥性肺炎の予防
