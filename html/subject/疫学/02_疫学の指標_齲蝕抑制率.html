齲蝕抑制率

齲蝕抑制率とは

フッ化物応用などの予防処置の効果を評価するための指標。対照群と比較して、どれだけう蝕の増加を抑えられたかを示す。

計算式

齲蝕抑制率(%) = (対照群の増加DMF − 実験群の増加DMF) ÷ 対照群の増加DMF × 100

増加DMFの計算

増加DMF = 調査終了時のDMF − 調査開始時のDMF
計算のポイント
  • 分子は「対照群 − 実験群」の順
  • 分母は「対照群」の増加DMF
  • 実験群と対照群を間違えないこと

計算例

群 開始時DMF 終了時DMF 増加DMF
A校（フッ化物洗口あり） 0.0 1.2 1.2
B校（対照群） 0.0 2.1 2.1

齲蝕抑制率 = (2.1 − 1.2) / 2.1 × 100 = 0.9 / 2.1 × 100 ≒ 43%

齲蝕抑制率の解釈

  • 高い値：予防効果が高い
  • 低い値：予防効果が低い
  • 0%：効果なし（対照群と同じ）
  • 負の値：逆効果（通常はあり得ない）

フッ化物洗口の齲蝕抑制率は一般的に30〜80%程度とされている。

国試過去問

108D53【計算】

フッ化物洗口法を実施しているA小学校と実施していないB小学校における1年時と6年時の1人平均DMF歯数を図に示す。
フッ化物洗口法による齲蝕抑制率を求めよ。ただし、小数点以下第1位を四捨五入すること。

正解：43%

【解説】
1. A小学校（実験群）：増加DMF = 1.2 − 0 = 1.2
2. B小学校（対照群）：増加DMF = 2.1 − 0 = 2.1
3. 齲蝕抑制率 = (2.1 − 1.2) / 2.1 × 100
　= 0.9 / 2.1 × 100 = 42.857...
4. 小数点以下第1位を四捨五入 → 43%

試験での注意点
  • 実験群と対照群を正しく識別する
  • 「増加DMF」を先に計算してから式に代入
  • 四捨五入の指示に従う
