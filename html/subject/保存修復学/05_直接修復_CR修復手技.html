保存修復学 / 直接修復

CR修復手技

CR修復の基本手順

直接CR修復の手順
  1. 窩洞形成・感染歯質除去
  2. 隔壁装着（2級窩洞：ウェッジ→マトリックス→リテーナー）
  3. 歯面処理（エッチング→プライミング→ボンディング）
  4. CR充填（積層充填）
  5. 光照射
  6. 形態修正・研磨（24時間以上経過後）

齲蝕象牙質の除去

層別名細菌再石灰化齲蝕検知液対応
感染層（外層）第一層あり不能濃染除去
無菌層（内層）第二層なし可能淡染保存

齲蝕検知液の使用法

  • 滴下 → 10秒間静置 → 水洗 → 乾燥 → 判別
  • 濃染部を除去後、再び染色して繰り返す
  • ポリプロピレングリコール液：不染状態まで除去
  • プロピレングリコール液：濃いピンクは保存（淡染部まで削除しない）

CR修復の窩洞形態

CR修復で不要になる形態
  • 予防拡大：不要（M.I.の概念）
  • 保持形態：不要（接着で保持）

※抵抗形態、便宜形態、窩縁形態は必要

ベベルの種類と適応

種類適応
ストレートベベル前歯部唇・舌側面、4級修復
ノンベベル臼歯部咬合面（咬合力負荷部）
ラウンドベベル臼歯部咬合面、前歯部

ベベル付与の目的

  • 接着面積の増大
  • 窩縁部亀裂（ホワイトマージン）の防止
  • 色調適合性の向上

※拘止効力の付与、重合収縮の補償は目的ではない

Cファクター（C値）

Cファクター = 接着面積 / 非接着面積

窩洞形態接着面積/非接着面積C値
1面接着（開放窩洞）1/50.2
3面接着3/31.0
5面接着（箱型窩洞）5/15.0

C値が大きい → コントラクションギャップが生じやすい → 分割積層充填で予防

隔壁法

修復部位隔壁の種類
2級修復（隣接面）メタルマトリックスバンド、トッフルマイヤー式リテーナー、ウェッジ
唇・頬側面歯頸部修復サービカルマトリックス（透明で光照射可能）
切縁隅角を含む修復クラウンフォーム
くさび状欠損のCR修復に必要な器材
  • ガムリトラクター：歯肉排除で歯頸部を露出
  • サービカルマトリックス：歯頸部用の透明マトリックス

※くさび状欠損は隣接面ではないため、ウェッジ・セパレーターは使用しない

補修修復の手順

  1. ウェッジ挿入
  2. マトリックス装着
  3. リテーナー装着
  4. シランカップリング剤塗布（既存CRフィラーへの接着）
  5. ボンディング材塗布
  6. CR充填・光照射

複数歯修復の順序

  1. 全ての歯の感染歯質を先に除去
  2. 1歯ずつCR修復を完成させる
  3. 隣接歯完成後に次の歯の隔壁を装着

過去問

103D45

齲蝕検知液で染色し、濃染部の歯質を除去中。次に行うのはどれか。

a 接着操作を行う
b ベベルを付与する
c 再び齲蝕検知液で染色する
d 水酸化カルシウム剤を貼付する
e ラウンドバーでさらに除去する
正解：c

【解説】齲蝕検知液で濃染部を除去した後は、再び染色して残存する感染象牙質の有無を確認。「染色→除去」を繰り返す。

105C118

メタルインレーと比較してCR修復で不要になるのはどれか。2つ選べ。

a 予防拡大
b 保持形態
c 抵抗形態
d 便宜形態
e 窩縁形態
正解：a, b

【解説】CR修復は接着を基本とするため、予防拡大（M.I.の概念で不要）と保持形態（アンダーカット等不要）は不要。

113A87

上顎前歯唇側面のCR修復窩洞にベベルを付与する目的はどれか。3つ選べ。

a 拘止効力の付与
b 重合収縮の補償
c 接着面積の増大
d 窩縁部亀裂の防止
e 色調適合性の向上
正解：c, d, e

【解説】ベベル付与の目的は、接着面積の増大、窩縁部亀裂の防止、色調適合性の向上。拘止効力はメタルインレーの概念。

108A102

Cファクターが最も大きい窩洞はどれか。

正解：5面接着の箱型窩洞（C値5.0）

【解説】Cファクター＝接着面積/非接着面積。5面接着（1面のみ開放）の窩洞がC値最大。

109D2

小臼歯部頬側歯頸部のくさび状欠損のCR修復。使用する器材はどれか。2つ選べ。

a ウェッジ
b ガムリトラクター
c サービカルマトリックス
d エリオットのセパレーター
e メタルマトリックスバンド
正解：b, c

【解説】くさび状欠損は隣接面ではなく頬側歯頸部の欠損。ガムリトラクター（歯肉排除）とサービカルマトリックス（歯頸部用隔壁）を使用。ウェッジ、セパレーターは隣接面用。

112D67

既存CR修復物の補修修復（2級窩洞）で4番目に行う処理はどれか。

a ウェッジ挿入
b マトリックス装着
c ボンディング材塗布
d リング状リテーナー装着
e シランカップリング剤塗布
正解：e

【解説】補修修復の手順：①ウェッジ→②マトリックス→③リテーナー→④シランカップリング剤→⑤ボンディング。シランカップリング剤は既存CRのフィラーと新しいCRを結合させる。

113A90

上顎右側第一・第二小臼歯の複数歯CR修復。治療過程の正しい順序は？

正解：上顎右側第二小臼歯感染歯質除去→上顎右側第一小臼歯感染歯質除去→上顎右側第一小臼歯CR修復→上顎右側第二小臼歯隔壁装着→上顎右側第二小臼歯CR修復

【解説】複数歯修復はまず全て感染歯質除去、次に1歯ずつ完成。隣接歯を完成させてから次の歯の隔壁を装着。
