薬理学 / 薬物適用上の注意点

高齢者

高齢者の薬物動態の変化

高齢者は加齢に伴って肝機能や腎機能が低下しており、薬物投与には細心の注意が必要。また、年齢と代謝排泄能の低下は一律でなく個人差が大きい。

高齢者で増加するもの

項目 臨床的意義
体脂肪率 脂溶性薬物の分布容積が増加
生物学的半減期 薬物が体内に長く留まる → 蓄積しやすい
血中遊離型薬物量 アルブミン低下により作用増強
有害作用発現率 副作用が出やすい

高齢者で減少するもの

項目 臨床的意義
肝機能（肝血流量↓） 薬物代謝能の低下
腎機能（腎血流量↓） 薬物排泄能の低下
体内水分量 水溶性薬物の血中濃度が上昇
血中アルブミン量 遊離型薬物が増加 → 作用増強
全身クリアランス 薬物の消失が遅延

ポリファーマシー（多剤併用）

ポリファーマシーとは、多くの薬剤が処方されている状態で、薬物有害事象のリスクが増加する。一般的に6種類以上の薬剤併用で有害事象が増加。

ポリファーマシーの要因

  • 併科受診：複数の医療機関から処方
  • 多職種連携の欠如：情報共有不足
  • 処方カスケード：副作用に対してさらに薬を追加

ポリファーマシー患者への対応

  • 薬剤師に処方内容を相談する
  • 服薬のアドヒアランスを確認する
  • 勝手に休薬を指示してはいけない

服薬アドヒアランス

アドヒアランスとは、患者が積極的に治療方針の決定に参加し、その決定に従って治療を受けること。

高齢者でアドヒアランスが低下する要因

  • 摂食嚥下障害：錠剤が飲み込めない
  • 認知機能低下：飲み忘れ、重複服用
  • ポリファーマシー：薬が多すぎて管理困難
転倒リスクを高める薬物
  • 利尿薬：起立性低血圧、脱水
  • 抗不安薬：ふらつき、筋弛緩作用
  • その他：降圧薬、睡眠薬、抗精神病薬など

過去問で実力チェック

107C68

薬物動態のうち、高齢者で低下するのはどれか。2つ選べ。

a 薬物代謝能
b 薬物排泄能
c 血中遊離型薬物濃度
d 水溶性薬物血中濃度
e 脂溶性薬物分布容積
正解：a, b

【解説】高齢者では肝機能低下により薬物代謝能が、腎機能低下により薬物排泄能が低下する。血中遊離型薬物濃度はアルブミン低下により増加。水溶性薬物血中濃度は体内水分量低下により増加。脂溶性薬物分布容積は体脂肪率増加により増加。

116A80

在宅療養におけるポリファーマシーの要因になるのはどれか。2つ選べ。

a 併科受診
b 和漢薬への変更
c 多職種連携の欠如
d 服薬カレンダーの利用
e 後発医薬品〈ジェネリック医薬品〉への変更
正解：a, c

【解説】併科受診は複数の医療機関から別々に薬が処方される原因。多職種連携の欠如は情報共有不足により重複処方の原因となる。和漢薬への変更・後発医薬品への変更は薬の数を増やさない。服薬カレンダーはむしろ服薬管理に有効。

115C49

服用により要介護高齢者の転倒リスクが高くなるのはどれか。2つ選べ。

a 利尿薬
b 抗不安薬
c 骨吸収抑制薬
d 尿酸排泄促進薬
e 直接トロンビン阻害薬
正解：a, b

【解説】利尿薬は脱水・電解質異常・起立性低血圧を起こし転倒リスクを高める。抗不安薬（ベンゾジアゼピン系など）はふらつき・筋弛緩作用により転倒リスクを高める。骨吸収抑制薬は骨粗鬆症治療薬で転倒リスクとは無関係。

116C63

高齢者において服薬アドヒアランスが低下する要因となるのはどれか。3つ選べ。

a 摂食嚥下障害
b 認知機能低下
c ポリファーマシー
d 薬剤耐性菌の増加
e 処方・調剤の一元管理
正解：a, b, c

【解説】摂食嚥下障害：錠剤が飲み込めない。認知機能低下：飲み忘れ・重複服用。ポリファーマシー：薬が多すぎて管理困難。薬剤耐性菌は細菌の問題でアドヒアランスとは無関係。処方・調剤の一元管理はむしろアドヒアランス向上に有効。

114B53

在宅療養中の多剤併用〈ポリファーマシー〉患者に対する適切な対応はどれか。2つ選べ。

a 薬剤師に処方内容を相談する。
b 主治医受診まで休薬を指示する。
c 服薬のアドヒアランスを確認する。
d 日々の体調で調節するよう指示する。
e 訪問看護師に錠剤の粉砕を指示する。
正解：a, c

【解説】薬剤師への相談とアドヒアランスの確認が適切。勝手に休薬を指示してはいけない（医師の判断が必要）。日々の体調で調節は危険。錠剤の粉砕は薬剤師の業務。

試験のポイント
  • 高齢者で低下：薬物代謝能・排泄能（肝・腎機能↓）
  • 高齢者で増加：半減期・遊離型薬物・有害作用発現率
  • ポリファーマシーの要因：併科受診・多職種連携の欠如
  • 転倒リスク：利尿薬・抗不安薬
