矯正 / 矯正装置

予測模型上で製作する装置

予測模型（セットアップモデル）

予測模型（セットアップモデル）は、矯正治療後の歯列を予測して作製する模型。歯を1本ずつ切り離して理想的な位置に排列し直す。

予測模型の用途

  • 固定の強さの判定：抜歯空隙の閉鎖に必要な固定の程度を評価
  • 治療計画の立案：治療後の歯列・咬合を視覚化
  • トゥースポジショナーの製作：理想的歯列位置での装置製作
  • 外科的矯正治療の計画：手術後の咬合を予測

トゥースポジショナー【最重要】

トゥースポジショナー（Tooth Positioner、ダイナミックポジショナー）は、予測模型上で製作する可撤式の保定装置。動的治療終了後の微調整と保定を兼ねる。

トゥースポジショナーの特徴【頻出】
  • 高分子弾性材料（シリコーンゴム）で製作
  • 予測模型（セットアップモデル）上で製作
  • 金属を使用しない → 金属アレルギーに安全
  • バンド装着不要（可撤式）
  • 構成咬合の採得不要
  • 動的治療終了後の微調整＋保定が目的

作用機序

予測模型上で製作されたトゥースポジショナーを口腔内に装着すると、現在の歯列と予測歯列との差により弾性力が発生し、歯を理想的な位置へ誘導する。

使用法

  • マルチブラケット装置撤去後に使用
  • 咬むことによって歯および歯列の安定をはかる
  • 日中の使用は困難なため、主に就寝時に装着

トゥースポジショナー vs 他の装置

項目 トゥースポジショナー アクチバトール等
製作に必要な模型 予測模型 現在の歯列模型
構成咬合の採得 不要 必要
材料 シリコーンゴム（高分子弾性材料） レジン＋金属線
金属アレルギー 心配不要 注意が必要
バンド装着 不要 不要
使用時期 動的治療終了後 動的治療中

保定装置の分類

可撤式保定装置

装置 特徴 材料
トゥースポジショナー 予測模型上で製作、微調整＋保定 シリコーンゴム
Hawleyタイプリテーナー 唇側線＋レジン床、最も汎用性が高い レジン＋金属線
Beggタイプリテーナー 前歯部の保定に適する レジン＋金属線
ラップアラウンドリテーナー 歯列全体を包み込む レジン＋金属線

固定式保定装置

  • 犬歯間保定装置：下顎前歯部の保定、ワイヤーで犬歯間を連結
  • ボンデッドリテーナー：歯面に直接ワイヤーを接着

過去問

114C36

矯正装置製作のための模型の写真を示す。製作するのはどれか。1つ選べ。

a Fränkel装置
b バイオネーター
c リップバンパー
d Hawleyタイプリテーナー
e ダイナミックポジショナー〈トゥースポジショナー〉
正解：e

【解説】歯を1本ずつ切り離して理想的位置に排列した予測模型（セットアップモデル）から製作するのはトゥースポジショナー。他の装置は現在の歯列模型から製作。

102B53

保定装置で高分子弾性材料を用いるのはどれか。1つ選べ。

a アクチバトール
b 犬歯間保定装置
c トゥースポジショナー
d Beggタイプリテーナー
e Hawleyタイプリテーナー
正解：c

【解説】トゥースポジショナーはシリコーンゴム（高分子弾性材料）で製作される。他の保定装置はレジンと金属線で製作。アクチバトールは保定装置ではなく機能的矯正装置。

104A102

金属アレルギーを有する患者に使用する際に注意を要するのはどれか。すべて選べ。

a ヘッドギア
b リップバンパー
c トゥースポジショナー
d Hawleyタイプリテーナー
e Nanceのホールディングアーチ
正解：a, b, d, e

【解説】金属を使用する装置は金属アレルギーに注意が必要。トゥースポジショナーはシリコーンゴム製で金属を使用しないため、金属アレルギー患者にも安全。

103A46

上顎の小臼歯抜去によるマルチブラケット治療を計画した。片側の歯を排列した診断用予測模型の写真を示す。矢印の空隙から判定するのはどれか。1つ選べ。

a 固定の強さ
b 矯正力の大きさ
c 矯正力の作用様式
d 動的治療期間
e 保定期間
正解：a

【解説】予測模型で片側だけ歯を排列し、抜歯空隙の配分を確認することで固定の強さを判定できる。空隙が前方に多く残れば強い固定が必要、後方に多く残れば弱い固定でよい。

出題パターンの整理
  • 予測模型で製作 → トゥースポジショナー
  • 高分子弾性材料 → トゥースポジショナー（シリコーンゴム）
  • 金属アレルギーに安全 → トゥースポジショナー
  • 構成咬合の採得 → トゥースポジショナーは不要
  • 予測模型の用途 → 固定の強さの判定、治療計画

参考：歯科矯正学（相馬）p.306（トゥースポジショナー）
