各論III / 良性腫瘍

顎骨腫瘍（良性腫瘍・腫瘍類似疾患）

国試の出題ポイント
  • 画像所見の鑑別：ナイフカット状歯根吸収（エナメル上皮腫）、テニスラケット状隔壁（歯原性粘液腫）、すりガラス様（線維性異形成症）
  • 治療法選択：開窓術 vs 摘出・骨削除 vs 顎骨切除の適応
  • 基底細胞母斑症候群：多発性顎嚢胞 + 二分肋骨 + 手掌点状小窩 + 大脳鎌石灰化
  • 病理組織所見：幻影細胞（石灰化嚢胞性歯原性腫瘍）、錯角化性扁平上皮（歯原性角化嚢胞）

1. エナメル上皮腫

本態

  • 歯原性上皮に由来する最も頻度の高い歯原性腫瘍
  • 歯胚のエナメル器に類似した組織像を示す
  • 良性腫瘍だが局所浸潤性が強い

好発年齢・好発部位

  • 好発年齢：20〜40代
  • 好発部位：下顎臼歯部〜下顎枝（上顎より下顎が圧倒的に多い）

症状

  • 無痛性の顎骨膨隆
  • 進行すると羊皮紙様感（骨の菲薄化による）
  • 歯の移動・傾斜
  • オトガイ神経麻痺は稀（悪性腫瘍との鑑別点）

画像所見

  • X線：境界明瞭な単房性または多房性（石鹸泡状）透過像
  • ナイフカット状の歯根吸収（切られたような吸収）
  • CT：頬舌的膨隆が顕著
  • 歯原性角化嚢胞は近遠心的に増大（鑑別点）

病理組織所見

  • 腫瘍実質：内エナメル上皮類似の高円柱状細胞が最外層に柵状配列
  • 内部：エナメル髄類似の星状細胞
  • 組織型：濾胞型、叢状型、基底型、顆粒型など

2. 歯原性角化嚢胞

本態

  • 歯堤または歯原性上皮に由来する発育性歯原性嚢胞
  • 2005年WHO分類で「角化嚢胞性歯原性腫瘍」に分類 → 2017年分類で嚢胞に戻る
  • 再発しやすい（娘嚢胞の存在、嚢胞壁の増殖能）

好発年齢・好発部位

  • 好発年齢：20〜30代、50〜70代（二峰性）
  • 好発部位：下顎臼歯部〜下顎枝部

画像所見

  • X線：境界明瞭な単房性または多房性透過像
  • CT：近遠心的に増大（エナメル上皮腫は頬舌的）
  • エナメル上皮腫、含歯性嚢胞との鑑別は病理組織診断が必要

病理組織所見

  • 嚢胞壁は錯角化性重層扁平上皮で裏層
  • 基底細胞は柵状配列（明瞭な基底細胞層）
  • 嚢胞腔内にオカラ状の角化物
  • 嚢胞壁内に娘嚢胞を認めることがある

治療

  • 摘出・骨削除（搔爬）が基本
  • 大きな病変では開窓術で縮小後に摘出
  • 娘嚢胞の取り残し防止のため摘出後に創面の骨削除を行う
基底細胞母斑症候群（Gorlin症候群）

歯原性角化嚢胞が多発する遺伝性疾患。PTCH1遺伝子異常。常染色体優性遺伝。

  • 多発性顎嚢胞（歯原性角化嚢胞）
  • 二分肋骨など肋骨異常
  • 手掌・足底の点状小窩（pit）
  • 大脳鎌の石灰化
  • 基底細胞癌の多発

※口蓋裂は副症状（主症状ではない）

3. 石灰化嚢胞性歯原性腫瘍（Gorlin嚢胞）

本態

  • 歯原性上皮由来の腫瘍で、幻影細胞（ゴースト細胞）を特徴とする
  • 石灰化物を伴うことが多い

好発年齢・好発部位

  • 好発年齢：10〜30代
  • 好発部位：上下顎前歯〜小臼歯部

画像所見

  • X線：境界明瞭な透過像＋内部に点状不透過像（石灰化像）
  • 歯の移動・歯根吸収を伴うことあり

病理組織所見

  • 嚢胞壁に幻影細胞（ゴースト細胞）：核の消失した好酸性の細胞
  • 歯原性上皮細胞の柵状配列
  • 石灰化物の沈着

4. 歯原性粘液腫

本態

  • 歯原性間葉組織由来の腫瘍
  • 粘液様基質と星状・紡錘形細胞からなる

好発年齢・好発部位

  • 好発年齢：20〜40代
  • 好発部位：下顎臼歯部

画像所見

  • X線：多房性透過像
  • テニスラケット状の隔壁（枝状内部構造）

病理組織所見

  • 豊富な粘液様基質内に星状・紡錘形細胞が散在
  • 線維成分は少ない

5. 歯牙腫

本態

  • 歯原性上皮と歯原性間葉の両方から構成される腫瘍
  • エナメル質、象牙質、セメント質などを形成
  • 過誤腫的性格が強い

分類

分類特徴画像所見
集合性歯牙腫多数の小歯牙様構造小さな歯様不透過像の集合
複雑性歯牙腫無秩序な硬組織塊不整形の不透過像

好発部位

  • 集合性：上顎前歯部
  • 複雑性：下顎臼歯部

6. 非歯原性腫瘍

乳頭腫

  • 本態：重層扁平上皮の外向性増殖による良性腫瘍
  • 原因：HPV感染（HPV-6, HPV-11が多い）、慢性刺激
  • 好発部位：口蓋、舌、歯肉
  • 病理：上皮の肥厚と樹枝状伸長、上皮突起の軸を形成する線維性結合組織

線維腫

  • 本態：線維組織の増殖による良性腫瘍
  • 原因：慢性刺激（不適合義歯など）
  • 腫瘍性増殖を伴わない有茎性のものは線維性ポリープ

神経線維腫・von Recklinghausen病

  • 本態：Schwann細胞と線維の増殖による良性腫瘍
  • 単発性と多発性（von Recklinghausen病＝神経線維腫症I型）
  • von Recklinghausen病の症状：多発性神経線維腫、カフェオレ斑、消化管・骨・神経症状
  • 常染色体優性遺伝（NF-1遺伝子異常）

骨腫

  • 本態：成熟した骨の腫瘍性増殖
  • 好発部位：犬歯窩、硬口蓋、上顎結節、下顎臼歯部
  • 画像所見：境界明瞭な均一な不透過像
  • Gardner症候群の一症状として多発することあり
鑑別が重要な症候群
症候群皮膚所見顎骨所見その他

7. 腫瘍類似疾患

線維性異形成症

  • 本態：骨髄部分に線維組織と骨組織が増生する非腫瘍性病変
  • 単骨性と多骨性がある
  • 多骨性が顔面骨に好発するものはMcCune-Albright症候群の一症状
  • 好発年齢：10〜20代（成長期に進行、成長終了後に停止）
  • 症状：顎骨の骨様硬の無痛性膨隆
  • 画像所見：境界不明瞭なすりガラス様不透過像
  • 血中ALP高値（骨代謝亢進を反映）
  • 病理：増殖した線維性結合組織中に不規則かつ幼若な骨梁形成
  • 治療：障害がなければ経過観察、必要に応じて骨減量術
  • 原則的に成長期終了後に手術

エプーリス

  • 本態：歯の存在する歯肉に限局して生じる線維性結合組織の増殖
  • 原因：慢性刺激、炎症
  • 好発年齢：20〜30代女性
  • 好発部位：上顎前歯部唇側歯間乳頭部
種類特徴
線維性エプーリス線維性結合組織が主体
線維腫性エプーリス線維腫に由来
血管腫性エプーリス毛細血管の増殖、血管腫と類似
巨細胞性エプーリス多核巨細胞が多数存在
