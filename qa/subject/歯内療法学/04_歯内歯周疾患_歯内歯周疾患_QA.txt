# 歯内-歯周疾患 Q&A
@brushup: 2026-01-20

## 概念

Q: 歯髄と歯周組織の交通経路は？
A: 根尖孔、側管・根管側枝、口蓋裂溝（上顎前歯）

---

## 分類

Q: 歯内-歯周疾患のClass I の名称と主たる原因は？
A: 歯内疾患由来型、根尖性歯周炎

Q: 歯内-歯周疾患のClass II の名称と主たる原因は？
A: 歯周疾患由来型、進行した歯周炎

Q: 歯内-歯周疾患のClass III の名称と主たる原因は？
A: 複合型（true combined lesion）、両方が独立発症し連続

Q: 歯内-歯周疾患で歯髄が壊死しているのは？
A: Class I と Class III
   [混同注意] Class II は歯髄生活

Q: 歯内-歯周疾患で歯髄が生活しているのは？
A: Class II

---

## 各病型の臨床的特徴

Q: 歯内-歯周疾患で骨吸収がU字型で患歯のみに見られるのは？
A: Class I

Q: 歯内-歯周疾患で骨吸収がV字型で全顎的に見られるのは？
A: Class II

Q: 歯内-歯周疾患で患歯のポケットが局部のみなのは？
A: Class I

Q: 歯内-歯周疾患で全顎的に歯周ポケットが存在するのは？
A: Class II と Class III

---

## 診断

Q: 歯内-歯周疾患のClass分類を決定するために最も重要な検査は？
A: 歯髄電気診・温度診（歯髄の生死判定）

Q: 歯内-歯周疾患の診断に必要な3つの検査は？
A: 歯髄電気診・温度診（歯髄の生死）、プロービング（ポケットの範囲）、エックス線（骨吸収パターン）

---

## 診断のポイント

Q: 歯髄が壊死している場合、歯内-歯周疾患のどのClassを考える？
A: Class I または Class III

Q: 歯髄が生活している場合、歯内-歯周疾患のどのClassを考える？
A: Class II

Q: 歯周ポケットが局部のみの場合、歯内-歯周疾患のどのClassを考える？
A: Class I

Q: 歯周ポケットが全顎的な場合、歯内-歯周疾患のどのClassを考える？
A: Class II または Class III

---

## 治療

Q: Class I（歯内疾患由来型）でまず行うべき治療は？
A: 感染根管治療
   [混同注意] この時期は歯周治療（ルートプレーニング等）は行わない

Q: Class I で感染根管治療後の経過観察で確認するのは？
A: ポケットの消失

---

## Class II（歯周疾患由来型）

Q: Class II で急性症状がある場合、まず行うべき治療は？
A: 歯内治療（抜髄）

Q: Class II の急性症状の原因は？
A: 上行性（逆行性）歯髄炎

---

## Class III（複合型）

Q: Class III の治療は？
A: 歯内治療と歯周治療の両方
   [混同注意] 歯内治療を優先し、終わり次第歯周治療を行う

---

[116A28] ★★★
Q: 歯内-歯周疾患の診断に必要な検査は？
A: 温度診、歯髄電気診、プロービング

[他の選択肢との違い]
- 温度診: 歯髄の生死判定に必要 ← 正解
- 麻酔診: 原因歯の特定に用いる（歯内-歯周疾患のClass分類には不要）
- 歯髄電気診: 歯髄の生死判定に必要 ← 正解
- プロービング: 歯周ポケットの範囲・深さを評価 ← 正解
- レーザー蛍光強度測定: 齲蝕の検出に用いる

[ポイント]
歯内-歯周疾患の診断 ＝ Class分類
Class分類 ＝ 歯髄の生死（電気診・温度診）＋ ポケットの範囲（プロービング）

---

[112C80] ★★★
Q: 遠心のみポケットが深い場合、次に行うべき検査は？
A: 歯髄電気診

[他の選択肢との違い]
- 透照診: 歯の亀裂の検出に用いる
- 麻酔診: 原因歯の特定に用いる
- 楔応力検査: 歯の破折の検出に用いる
- 歯髄電気診: 歯髄の生死を判定しClass分類を行う ← 正解
- レーザー蛍光強度測定: 齲蝕の検出に用いる

[ポイント]
局部的な深いポケット → 歯内-歯周疾患を疑う
まず歯髄電気診でClass分類（歯髄壊死ならClass I、生活ならClass II）

---

[108B9] ★★★
Q: 歯内-歯周疾患で歯髄壊死の場合、まず行うべき処置は？
A: 感染根管治療

[他の選択肢との違い]
- 抜歯: まず保存治療を試みる
- 暫間固定: 動揺の抑制であり根本治療ではない
- 感染根管治療: 歯髄壊死（Class I または III）ではまず感染根管治療 ← 正解
- 抗菌薬の局所投与: 補助的治療であり根本治療ではない
- ルートプレーニング: 根管治療後に行う（この時期は行わない）

[ポイント]
歯髄壊死 → Class I（歯内疾患由来型）→ まず感染根管治療
ルートプレーニングは根管治療後に検討
