口腔内診査

OHI（口腔衛生指数）

OHI（oral hygiene index）は、Greene & Vermillionが1960年に提唱した指標で、プラーク（debris）と歯石（calculus）の付着状態を数量化し、口腔清掃状態の判定に用いる。

診査部位

  • すべての歯を対象とし、頬（唇）・舌面それぞれについて評価
  • 上下顎を6つのブロックに分け、各ブロックの最高点を採用

DI（Debris Index）の評価基準

点数 診査基準
0 プラークおよび外因性付着物を認めない
1 歯面の1/3以内のプラーク付着、または外因性付着物あり
2 歯面の1/3〜2/3のプラーク付着
3 歯面の2/3以上のプラーク付着

CI（Calculus Index）の評価基準

点数 診査基準
0 歯石の付着を認めない
1 歯面の1/3以内の歯肉縁上歯石付着、または歯肉縁下歯石の点状付着
2 歯面の1/3〜2/3の歯肉縁上歯石付着、または歯肉縁下歯石の帯状付着
3 歯面の2/3以上の歯肉縁上歯石付着、または歯肉縁下歯石の帯状付着

OHIの計算

  • 個人のDI = プラーク点数の合計 / 被験ブロック数（通常6）
  • 個人のCI = 歯石点数の合計 / 被験ブロック数（通常6）
  • 個人のOHI = DI + CI（最大12点）
  • 集団のOHI = 個人のOHIの合計 / 被験者数
OHIの特色
  • プラークと歯石を個別または同時に評価できる
  • 世界的に広く用いられている

OHI-S（簡略化口腔衛生指数）

OHI-S（Greene & Vermillion, 1964）は、OHIを簡略化し、診査部位を特定の6歯に限定した部分診査法。

対象歯

位置 対象歯 診査面
上顎 右側第一大臼歯、中切歯、左側第一大臼歯 頬・唇側面
下顎 左側第一大臼歯、中切歯、右側第一大臼歯 大臼歯は舌側面、切歯は唇側面

注意：中切歯喪失時は反対側中切歯、第一大臼歯喪失時は第二大臼歯を診査

OHI-Sの計算

  • 個人のDI-S = プラーク点数の合計 / 被験歯数（通常6）（最大3点）
  • 個人のCI-S = 歯石点数の合計 / 被験歯数（通常6）（最大3点）
  • 個人のOHI-S = DI-S + CI-S（最大6点）
OHIとOHI-Sの違い
  • OHI：全顎を6ブロックで評価 → 最大12点
  • OHI-S：特定の6歯のみ評価 → 最大6点
  • OHI-Sは簡便で広く使用されている

過去問

100B86

歯垢染色後の口腔内写真（別冊No.3）を別に示す。OHIのDebris Indexで唇面を評価した時の正しい組合せはどれか。

※写真では各歯のプラーク付着状態が染め出されている

a 上顎中切歯 ―― 3点
b 上顎側切歯 ―― 3点
c 下顎中切歯 ―― 2点
d 下顎側切歯 ―― 2点
e 下顎犬歯 ―― 1点
正解：b

【解説】DIの評価基準に基づき、各歯面のプラーク付着状態を判定する。歯面の2/3以上にプラークが付着していれば3点となる。写真では上顎側切歯の唇面に2/3以上のプラーク付着が認められ、3点と評価される。
