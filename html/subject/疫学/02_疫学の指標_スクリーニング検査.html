疫学 / 疫学の指標

スクリーニング検査

スクリーニングとは

疾病をもつ可能性のある者をふるい分けし、無症状で治療可能な早期の段階で発見すること。二次予防の早期発見に相当する。

2×2表と指標

基本の2×2表

疾病あり 疾病なし
検査陽性(+) 真陽性 (a) 偽陽性 (b)
検査陰性(-) 偽陰性 (c) 真陰性 (d)

各指標の計算式

指標 計算式 意味
感度（敏感度） a/(a+c) 疾病ありを陽性と判定する確率
特異度 d/(b+d) 疾病なしを陰性と判定する確率
陽性的中率 a/(a+b) 陽性者のうち真に疾病ありの確率
陰性的中率 d/(c+d) 陰性者のうち真に疾病なしの確率
偽陽性率 b/(b+d) = 1-特異度 疾病なしを陽性と誤判定
偽陰性率 c/(a+c) = 1-感度 疾病ありを陰性と誤判定

陽性尤度比

陽性尤度比 = 感度 / (1-特異度) = 感度 / 偽陽性率

カットオフ値の変化

カットオフ値を低く設定すると
  • 感度 → 上がる
  • 特異度 → 下がる
  • 偽陽性率 → 高くなる

重要：致命率が高い疾病では感度を優先する（見逃しを防ぐ）

ROC曲線

  • 縦軸：感度
  • 横軸：1-特異度（偽陽性率）
  • 曲線下面積（AUC）が大きいほど有用な検査
  • 左上に近い曲線ほど優れている

有病率と的中率

  • 有病率が変化しても感度・特異度は変わらない
  • 有病率↑ → 陽性的中率↑、陰性的中率↓
  • 有病率↓ → 陽性的中率↓、陰性的中率↑

国試過去問

104C96

疾病の有無とスクリーニング検査結果とを表に示す。
A/(A+B)はどれか。1つ選べ。

a 敏感度〈感度〉
b 特異度
c 陽性反応的中度
d 陰性反応的中度
e 偽陽性率
正解：a

【解説】A/(A+B)は「疾病ありの人のうち検査陽性の割合」で、これは感度の定義。感度=a/(a+c)と同じ形式。

106C72

死亡率の高い疾患のスクリーニング検査法の評価において、最も重視するのはどれか。1つ選べ。

a 敏感度〈感度〉
b 特異度
c 偽陽性率
d 陽性反応適中度
e 陰性反応適中度
正解：a

【解説】死亡率（致命率）が高い疾患では、見逃し（偽陰性）を防ぐため感度を優先する。

116D70

疾病の有無とスクリーニング検査値の分布の関係を図に示す。
カットオフ値を低く設定したときの数値の変化の組合せで正しいのはどれか。1つ選べ。

a 感度：上がる ── 特異度：上がる
b 感度：上がる ── 特異度：下がる
c 感度：下がる ── 特異度：上がる
d 感度：下がる ── 特異度：下がる
e 変化なし ── 変化なし
正解：b

【解説】カットオフ値を低くすると陽性判定が増えるため、感度は上がるが特異度は下がる。感度と特異度はトレードオフの関係。

115D90【計算】

ある成人集団に対して歯周病のスクリーニング検査を実施した結果、感度は0.90で特異度は0.80であった。この検査の尤度比（陽性尤度比）を求めよ。

正解：4.5

【解説】陽性尤度比 = 感度/(1-特異度) = 0.90/(1-0.80) = 0.90/0.20 = 4.5

113B27

5つの検査法のROC曲線を図に示す。スクリーニング検査に最も有用なのはどれか。1つ選べ。

a ア
b イ
c ウ
d エ
e オ
正解：a

【解説】ROC曲線では左上に近い（曲線下面積が大きい）ほど有用。アが最も左上に位置する。
