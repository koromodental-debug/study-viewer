歯周病学 / 歯周外科治療

フラップ手術

定義

フラップ手術（flap surgery）とは、歯周病変部の歯根面や歯槽骨欠損部の視野の確保ならびに器具の到達性を容易にするために骨膜を含んだ全層弁、または部分層弁を形成・翻転後、原因因子および病変の除去、あるいは改善などを図る歯周外科治療である。

意義

非外科的歯周治療では除去困難な深い歯周ポケットがある部位からの細菌や病変部の除去が可能であり、歯周外科治療の基本テクニックである。根分岐部病変の治療、骨移植術、GTR法や歯周形成手術の習得にも不可欠。

適応症
  • 4mm以上の歯周ポケット
  • 垂直性骨吸収
  • 高度な水平性骨吸収
  • 歯槽骨の形態異常
  • 根分岐部病変

フラップの分類

骨膜の有無による分類

種類構成歯槽骨
全層弁（粘膜骨膜弁）骨膜を含む露出する
部分層弁（粘膜弁）骨膜を含まない露出しない

形態による分類

種類切開法
エンベロップフラップ水平切開のみで封筒状に翻転
三角（トライアンギュラー）フラップ水平切開＋片側に縦切開
フルフラップ水平切開＋両側に縦切開

フラップの戻す位置による分類

位置目的・適応
元の位置通常のフラップ手術
歯冠側露出歯根面の被覆（十分な角化歯肉幅が必要）
根尖側付着歯肉幅の増加、ポケット除去（角化歯肉幅が狭くても可能）
側方露出歯根面の被覆、付着歯肉幅の増加

一般的なフラップ手術の術式

浸潤麻酔 → 切開 → 剥離 → 肉芽除去 → SRP → 縫合

術式の詳細

順序手技ポイント
1口腔内清拭・消毒・麻酔術前のプラークコントロール徹底
2プロービングポケットデプスの測定
3切開内斜切開（2mm以上のポケット）または歯肉溝内切開
4フラップの剥離・翻転全層弁を必要最小限の範囲で剥離
5切除歯肉片の除去二次切開でポケット部歯肉を遊離
6肉芽組織の除去骨欠損底部の郭清を十分に
7SRP直視下で残存歯石・病的セメント質を除去
8（必要時）骨整形・骨切除形態異常や浅い骨欠損の処置
9洗浄・フラップ内面処置一次創傷治癒を得るため緊密な接触を確認
10縫合（歯周パック）死腔を避け創傷治癒を促進

Widman改良フラップ手術

Widman改良フラップ手術は、最小の外科的侵襲で最大の治療効果を得ることを目的とした術式。フラップの剥離は根尖方向1〜2mm程度とし、歯槽骨欠損部は郭清のみにとどめ、可及的に歯槽骨の温存を図る。術後の不快症状が少なく、審美的にも優れている。

歯周外科治療の比較

術後に創面が露出する術式

注意：フラップ手術は創面を縫合するため露出しない。以下の術式は創面が露出する。

  • 遊離歯肉移植術：採取部位（口蓋）が露出
  • 歯肉弁側方移動術：供給側の創面が露出

付着歯肉幅が減少するリスクが高い術式

  • 歯肉切除術：角化歯肉を切除するため減少
  • 歯肉弁歯冠側移動術：歯肉を歯冠側に移動するため減少

骨縁下ポケットへの適応

歯肉切除術は骨縁下ポケットに適応できない（歯槽骨頂より根尖側の病変にアクセスできないため）

外科的侵襲の程度

最も侵襲が小さいのは歯周ポケット掻爬術（切開・剥離を行わない）

使用器具

器具用途
替刃メス（#11, 12, 15など）切開
歯肉剥離子（オルバンメス、カークランドメスなど）フラップの剥離
キュレット型スケーラー肉芽除去、SRP
骨ノミ・骨ヤスリ骨整形術
縫合針・縫合糸縫合

過去問

116C52

フラップ手術の治療過程を示す。
浸潤麻酔 → ① → ② → ③ → ④ → ⑤ →縫合
④に入るのはどれか。1つ選べ。ただし、①〜⑤はa〜eのいずれかに該当する。

a 切開
b 剥離
c 肉芽除去
d ボーンサウンディング
e スケーリング・ルートプレーニング
正解：c

【解説】フラップ手術の順序は「浸潤麻酔→切開→剥離→肉芽除去→SRP→縫合」。④に入るのは肉芽除去。ボーンサウンディングは術前の診査で行う。

113D58

フラップ手術に使用する器具の写真（別冊No.13）を別に示す。
使用順序で正しいのはどれか。1つ選べ。

a ア→イ→エ→オ→ウ
b イ→ア→オ→ウ→エ
c ウ→ア→オ→イ→エ
d ウ→イ→ア→オ→エ
e オ→ウ→ア→エ→イ
正解：c

【解説】器具の使用順序は術式の流れに対応。ウ（メス：切開）→ア（剥離子：剥離）→オ（キュレット：肉芽除去・SRP）→イ（縫合針：縫合）→エ（はさみ：糸切断）の順。

105C114

骨縁下ポケットに適応できないのはどれか。1つ選べ。

a GTR法
b 歯肉切除術
c 歯周ポケット掻爬術
d エナメルタンパク質の応用
e Widman改良フラップ手術
正解：b

【解説】歯肉切除術は骨縁下ポケットに適応できない。歯槽骨頂より根尖側の病変にはアクセスできないため。GTR法、エナメルマトリックスタンパク質、Widman改良フラップ手術は骨縁下ポケットに適応可能。

110C75

術後に創面が露出する歯周外科治療はどれか。2つ選べ。

a ENAP
b GTR法
c フラップ手術
d 遊離歯肉移植術
e 歯肉弁側方移動術
正解：d, e

【解説】遊離歯肉移植術は口蓋の採取部が露出。歯肉弁側方移動術は供給側の創面が露出。フラップ手術やENAP、GTR法は縫合により創面を閉鎖する。

114B31

付着歯肉幅が減少するリスクが高いのはどれか。2つ選べ。

a 新付着術
b 歯肉切除術
c 歯周ポケット掻爬術
d 歯肉弁歯冠側移動術
e Widman改良フラップ手術
正解：b, d

【解説】歯肉切除術は角化歯肉を切除するため付着歯肉幅が減少。歯肉弁歯冠側移動術は歯肉を歯冠側に移動させるため、歯肉歯槽粘膜境（MGJ）の位置は変わらず付着歯肉幅が減少する。

114D87

外科的侵襲が最も小さい歯周外科手術はどれか。1つ選べ。

a 歯肉切除術
b 歯槽骨切除術
c 歯周ポケット掻爬術
d 歯肉弁根尖側移動術
e Widman改良フラップ手術
正解：c

【解説】歯周ポケット掻爬術は切開・剥離を行わず、キュレットでポケット内壁を掻爬するのみのため、最も侵襲が小さい。
