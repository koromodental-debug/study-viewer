歯科麻酔学 / 留意すべき疾患・徴候

高齢者

老年期の疾患の特徴

高齢者の疾患の特徴
  • 複数の疾患を併発する（多疾患併存）
  • 完治が困難である（慢性・退行性疾患が多い）
  • 個人差が大きい（同年齢でも臓器機能に著しい差）
  • 環境に左右されやすい（気温変化、生活環境など）
  • 症状が非典型的（肺炎でも発熱しない、心筋梗塞でも胸痛を訴えない等）
  • 治療に対する反応性が低い（免疫機能・基礎体力の低下）
116C65

老年期の疾患の特徴はどれか。2つ選べ。

a 個人差が小さい。
b 完治が困難である。
c 複数の疾患を併発する。
d 環境要因に左右されにくい。
e 治療に対する反応性が高い。
正解：b, c

【解説】高齢者は慢性・退行性疾患が多く完治が困難であり、複数の疾患を同時に抱える。個人差は大きく（小さいは誤り）、環境に左右されやすく（されにくいは誤り）、治療への反応性は低下する（高いは誤り）。

老化に伴う生理的変化

呼吸器系

パラメータ変化機序
残気量（RV）増加肺弾性収縮力の低下 → 肺が縮みにくい
肺活量（VC）低下呼吸筋力低下＋胸郭コンプライアンス低下
咳嗽反射低下不顕性誤嚥 → 誤嚥性肺炎のリスク
ガス拡散能（DLCO）低下肺胞面積の減少、肺毛細血管床の減少
胸郭コンプライアンス低下肋軟骨の石灰化・骨化
肺コンプライアンス上昇肺弾性線維の変性 → 膨らみやすくなる
PaO2低下V/Q不均等の増加

注意：胸郭コンプライアンスは「低下」、肺コンプライアンスは「上昇」。混同しやすい。

107C73

老化に伴う呼吸器系の変化はどれか。1つ選べ。

a 残気量の増加
b 肺活量の増加
c 咳嗽反射の亢進
d ガス拡散能の上昇
e 胸郭コンプライアンスの上昇
正解：a

【解説】加齢により肺弾性収縮力が低下し、肺が縮みにくくなるため残気量は増加する。肺活量は低下（増加ではない）、咳嗽反射は低下（亢進ではない）、ガス拡散能は低下（上昇ではない）、胸郭コンプライアンスは低下（上昇ではない）。

循環器系

  • 心拍出量の低下（心室壁の肥厚・硬化 → 一回拍出量減少）
  • 動脈硬化による末梢血管抵抗の増大 → 収縮期血圧上昇
  • 圧受容体反射の低下 → 起立性低血圧を起こしやすい
  • β受容体感受性の低下 → 運動時の心拍数増加反応が鈍化

肝臓・腎臓

  • 肝クリアランス：30〜40%低下（CYP450の第I相反応が低下）
  • リドカインの半減期：高齢者140分 vs 若年者81分（約1.7倍に延長）
  • GFR：40歳以降、10年毎に約8 mL/min/1.73m2低下
  • 局所麻酔薬の投与量は減量を考慮

サルコペニア

定義

サルコペニア（sarcopenia）は、加齢に伴う骨格筋量および筋力の低下を特徴とする症候群。ギリシャ語のsarx（筋肉）+ penia（減少）に由来する。

分類

  • 一次性：加齢のみが原因
  • 二次性：低活動（廃用）、低栄養、疾患（悪液質等）が原因

歯科との関連

  • サルコペニア嚥下障害：嚥下関連筋群の筋力低下による摂食嚥下障害
  • 舌圧20 kPa未満 → 摂食嚥下障害に相当
  • オーラルフレイル：わずかなむせ・食べこぼし・滑舌低下 → 口腔機能低下 → 全身のフレイルへ
110B36

85歳の男性。摂食・嚥下障害を主訴として、訪問歯科診療の依頼があった。半年の間に10％の体重減少を示し、歩行は困難である。患者の舌上には食物残渣がみられる。訪問時の下肢の写真（別冊No.32）を別に示す。
この患者の状態を示すのはどれか。1つ選べ。

a アカラシア
b ジストニア
c サルコペニア
d ジスキネジア
e ディスアスリア
正解：c

【解説】85歳男性、摂食嚥下障害、半年で10%の体重減少、歩行困難、下肢の筋萎縮（写真） → サルコペニア。加齢に伴う骨格筋量・筋力の低下により、摂食嚥下機能も障害される。アカラシアは食道の運動障害。ジストニア・ジスキネジアは不随意運動。ディスアスリア（構音障害）は発話の障害で摂食嚥下障害とは異なる。

高齢者の歯科治療時の全身管理

局所麻酔の注意

  • 肝代謝・腎排泄の低下により薬物半減期が延長 → 投与量の減量を考慮
  • 少量ずつ分割投与し、投与毎に観察する
  • アドレナリンへの感受性亢進 → 慎重投与、モニター監視下で低圧・ゆっくり注入
  • 高血圧・糖尿病の患者にはフェリプレシンが比較的安全に使用できる

多剤併用（ポリファーマシー）

注意すべき薬剤歯科での問題
抗血栓薬（ワルファリン・DOAC・抗血小板薬）原則休薬しない。止血をしっかり行う
骨吸収抑制薬（BP製剤・デノスマブ）MRONJ（薬剤関連顎骨壊死）のリスク
Ca拮抗薬（ニフェジピン等）歯肉増殖の副作用

体位の配慮

  • 急な体位変換を避ける（起立性低血圧の予防）
  • 治療終了後はゆっくり起き上がらせる
  • バイタルサインの継続的モニタリング
