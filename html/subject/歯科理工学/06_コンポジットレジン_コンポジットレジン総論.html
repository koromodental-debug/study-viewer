コンポジットレジン総論

コンポジットレジンとは

コンポジットレジンは、マトリックスレジン（有機成分）とフィラー（無機成分）を複合した修復材料である。審美性に優れ、直接充填が可能なため、保存修復で広く使用される。

光重合型コンポジットレジンの構成成分【頻出】

光重合型コンポジットレジンは5つの成分から構成される。

5構成成分

成分 役割 具体例
マトリックスレジン 基質（有機成分） Bis-GMA、TEGDMA、UDMA
フィラー 強化材（無機成分） シリカ、アルミナ、ジルコニア
光増感剤 光で励起→重合開始 カンファーキノン（473nm）
重合禁止剤 保存中の重合防止 BHT、ハイドロキノン
色素 色調調整 各種顔料
光重合のしくみ
  • カンファーキノンが可視光（約470nm）で励起
  • 重合促進剤（第三級アミン）と反応
  • フリーラジカル発生 → モノマーが重合硬化

フィラーによる分類【頻出】

フィラーの粒径・種類により、コンポジットレジンは分類される。

フィラータイプの分類

タイプ フィラー粒径 特徴
マクロフィラー型 1〜50μm 機械的強度↑、研磨性↓
マイクロフィラー型 0.01〜0.04μm 研磨性↑、フィラー含有量↓
ハイブリッド型 複数サイズ混合 フィラー含有量↑、強度↑
ナノハイブリッド型 ナノフィラー含有 研磨性と強度を両立

マイクロフィラー型 vs ハイブリッド型【頻出】

なぜ差が生じるか

  • ハイブリッド型：複数サイズのフィラーを混合 → フィラー含有量が高い
  • マイクロフィラー型：超微粒子のみ → フィラー含有量が低い

物性の比較

物性 マイクロフィラー型 ハイブリッド型
フィラー含有量 低い 高い
弾性係数 小さい 大きい
引張強さ 弱い 強い
吸水性 大きい 小さい
重合収縮率 大きい 小さい
熱膨張係数 大きい 小さい
研磨性 良好 やや劣る
覚え方：フィラーが多いと
  • フィラー↑ → 強度↑、弾性係数↑（硬くて強い）
  • フィラー↑ → 収縮↓、膨張↓、吸水↓（レジン成分が少ない）

過去問演習

112B37

光重合型コンポジットレジンに含まれるのはどれか。すべて選べ。

a 色　素
b 光増感剤
c フィラー
d 重合禁止剤
e マトリックスレジン
正解：a, b, c, d, e

【解説】光重合型コンポジットレジンは以下の5成分から構成される。

  • a ○：色素 → 色調調整のため含有
  • b ○：光増感剤 → カンファーキノン（光で励起し重合開始）
  • c ○：フィラー → 無機成分（シリカなど）で強度向上
  • d ○：重合禁止剤 → 保存中の重合を防止
  • e ○：マトリックスレジン → 有機成分（Bis-GMAなど）
110C106

マイクロフィラー型と比べてハイブリッド型コンポジットレジンで大きくなるのはどれか。2つ選べ。

a 吸水性
b 弾性係数
c 引張強さ
d 重合収縮率
e 熱膨張係数
正解：b, c

【解説】ハイブリッド型はフィラー含有量が高いため、以下の違いが生じる。

  • a ×：吸水性 → ハイブリッド型で小さい（レジン成分↓）
  • b ○：弾性係数 → ハイブリッド型で大きい（フィラー↑）
  • c ○：引張強さ → ハイブリッド型で大きい（フィラー↑）
  • d ×：重合収縮率 → ハイブリッド型で小さい（レジン成分↓）
  • e ×：熱膨張係数 → ハイブリッド型で小さい（無機成分↑）
