体液

I. 体液の区分と組成

体液量

  • 成人男性で体重の60%（女性は脂肪が多いため55%）

加齢による体液量の変化

年齢 体液量（体重比）
新生児 75〜80%
乳児 70%
成人 60%（男性）、55%（女性）
高齢者 50〜55%

体液の区分と割合

区分 体重比 備考
細胞内液 40%（全体液量の2/3） 細胞内に存在
細胞外液 20%（全体液量の1/3） 細胞外に存在
　├ 間質液 15%（細胞外液の3/4） 細胞間を満たす
　└ 血漿 5%（細胞外液の1/4） 血管内の液体成分
電解質組成の特徴
  • 細胞外液：Na⁺が主な陽イオン（約140 mEq/L）、Cl⁻が主な陰イオン
  • 細胞内液：K⁺が主な陽イオン（約140 mEq/L）、リン酸・タンパク質が主な陰イオン
  • 血漿と間質液の違い：血漿にはタンパク質が多い（毛細血管壁を通過しにくい）

II. 血液

血液量と成分

  • 全血液量：体重の8%（6〜9%）、比重1.05〜1.07
  • 血球（細胞成分）：血液の45%
    • 赤血球（血球の90%以上）、白血球、血小板
  • 血漿（液性成分）：血液の55%

血液の機能

機能 内容
運搬 ガス（O₂、CO₂）、栄養素、ホルモン、代謝産物、熱
放熱 皮膚表在部の血管から放熱
酸塩基平衡 緩衝作用（H⁺+HCO₃⁻ ⇄ H₂CO₃ ⇄ H₂O+CO₂）
pHは7.35〜7.45に維持。H⁺は腎臓、CO₂は肺で排泄（開かれた緩衝系）
体液量の維持 膠質浸透圧による水分保持
免疫機能 白血球、抗体（液性成分）
止血と線溶 血小板、血液凝固因子、プラスミン

赤血球

  • ヒト赤血球は無核（分化の途上で脱核）でミトコンドリアをもたない
  • ヘモグロビン量：16 g/dL（男性）、14 g/dL（女性）
  • ヘマトクリット値：45%（男性）、42%（女性）
  • 寿命：約120日。肝臓または脾臓でマクロファージにより破壊

赤血球の産生と破壊

過程 内容
産生 骨髄の多能性幹細胞 → 赤芽球 → 赤血球
促進ホルモン：エリスロポエチン（O₂不足時に腎臓から分泌）
必要な物質：葉酸、ビタミンB₁₂（不足すると貧血）
破壊 ヘモグロビン → ヘム + グロビン
ヘム → 鉄 + ビリルビン
鉄は肝臓に貯蔵、ビリルビンは胆汁に含有されて腸管に分泌（便色）

血漿

  • 血液から細胞成分を除いた液体成分
  • 組成は間質液とほぼ等しいが、タンパク質が比較的多い
  • 主な血漿タンパク質：フィブリノゲン、アルブミン、γグロブリン

III. 止血（血液凝固）と線溶

一次止血（血小板凝集）

過程 内容
血小板の産生 骨髄中の巨核球から細胞質がちぎれて生じる。直径2〜3μm、血液1μLあたり15〜35万個
一次止血の開始 血管損傷 → 血管壁のコラーゲン露出 → 血中のvon Willebrand因子がコラーゲンに結合 → 血小板も結合
血小板の活性化 損傷部に結合した血小板は活性化され、ADPやトロンボキサンA₂を放出 → 他の血小板も活性化・凝集（血小板血栓）
血流阻害 凝集した血小板 → セロトニン分泌 → 血管収縮（血流阻害）→ 白色血栓

二次止血（血液凝固）

血小板の凝集が起こると同時に血液凝固反応が始まる。血漿中のさまざまな血液凝固因子が連続的に活性化される増幅反応（カスケード反応）として進行。

凝固経路
  • 内因系凝固：血管の内部損傷などで、露出したコラーゲンとの接触により開始
  • 外因系凝固：組織損傷によって放出された組織因子と第VII因子との接触により開始
  • 共通系凝固：内因系・外因系ともに第X因子の活性化以降は共通した反応経路

最終的に血漿中の可溶性タンパク質・フィブリノゲンが線維状のフィブリン（線維素）となり、血液の凝固塊が形成される（二次止血・赤色血栓）。

血液凝固因子

  • 活性化されるとプロテアーゼ活性を示し、次の因子を順次活性化していく
  • III、IV、VIII因子以外はすべて肝臓で合成される
  • II、VII、IX、X因子の合成はビタミンKに依存する
  • ワルファリンはビタミンKの代謝を阻害することで抗凝固作用を示す

線溶

  • フィブリン血栓が形成されると、フィブリン溶解反応（線維素溶解：線溶）も活性化される
  • フィブリン線維の生成後、プラスミンによるフィブリン血栓の溶解が始まる
  • 過度の血流障害や血管閉塞を起こさないよう作用する
内皮細胞 → 組織プラスミノゲンアクチベータ（活性化）→ プラスミノゲン → プラスミン → フィブリン（分解）→ フィブリン分解産物

IV. 血液型

ABO式血液型

血液型 赤血球（抗原） 血清（抗体）
A型 A型抗原 抗B抗体
B型 B型抗原 抗A抗体
AB型 A型抗原、B型抗原 抗体なし
O型 抗原なし 抗A抗体、抗B抗体

※輸血時に血液型を合わせないと凝集が起こり、不適合となる

Rh式血液型

  • ヒト赤血球上に存在するアカゲザルとの共通抗原の存在の有無による血液型
  • Rh抗原をもつ場合をRh（+）、もたない場合をRh（−）とする

V. 腎臓による体液量と浸透圧の調節

容量調節系と浸透圧調節系は、お互いに協調して体液量と浸透圧の調節を行っている。

容量調節系（体液量の調節）

体液量低下での調節系

レニン-アンジオテンシン-アルドステロン系

  • レニンの分泌は、尿細管中のNa（Cl）流量の低下や交感神経活動によっても促進される
  • 傍糸球体装置よりレニン分泌 → アンジオテンシノゲン → アンジオテンシンI → アンジオテンシンII（ACEによる変換、血管内皮細胞膜表面に多い）
  • アンジオテンシンII → 血管収縮、アルドステロン分泌促進（副腎皮質）
  • アルドステロン → 遠位尿細管・集合管でNa⁺再吸収促進 → 水も一緒に再吸収 → 体液量増加

体液量増加での調節系

  • 心房性Na利尿ペプチド（ANP）：Na⁺再吸収を抑制する（アルドステロン作用を抑制）
  • また、糸球体血管を拡張し、糸球体濾過量を増加させる
  • → Na⁺利尿促進 → 浸透圧が増加するが体液量が低下する → 体液量・血圧の回復

浸透圧調節系

  • バソプレシン（抗利尿ホルモン：ADH）：水の再吸収を促進する
  • 視床下部で産生、下垂体後葉から分泌
  • 遠位尿細管・集合管に作用 → 水の再吸収促進 → 体液浸透圧の低下
  • また、血管収縮作用もある → 血圧の回復

遠位尿細管・集合管に作用するホルモン

ホルモン 作用
バソプレシン（ADH） 水の再吸収を促進
アルドステロン Na⁺の再吸収を促進（Na⁺再吸収による間質浸透圧の上昇で水も一緒に再吸収）
心房性Na利尿ペプチド（ANP） Na⁺再吸収を抑制（アルドステロン作用を抑制）
パラトルモン（PTH） Ca²⁺の再吸収を促進
