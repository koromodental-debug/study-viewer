神経線維の分類と筋紡錘

出題のポイント
  • Aα線維（運動神経）が伝導速度最速
  • Aγ線維が錘内筋を収縮させる（筋紡錘の感度調節）
  • Ia群線維は筋紡錘からの求心性線維（伸張反射）
  • Aδ線維は象牙質擦過刺激による痛みを伝える

1. 神経線維の分類（Erlanger-Gasser分類）

軸索の伝導速度と直径は比例するので、軸索は太さによって群に分類される。

髄鞘 型 機能 線維径(μm) 伝導速度(m/秒)
有髄 Aα 固有受容感覚、体性運動 12〜20 70〜120（最速）
Aβ 触覚、圧覚 5〜12 30〜70
Aγ 筋紡錘への運動神経 3〜6 15〜30
Aδ 痛覚、温度覚、触覚 2〜5 12〜30
B 交感神経節前線維 <3 3〜15
無髄 C 痛覚、温度覚、交感神経節後線維 0.3〜1.3 0.5〜2.3

2. 求心性線維の分類（Lloyd-Hunt分類）

感覚神経にのみ適用され、受容器との対応にも注目した分類。

分類 受容器の種類 対応する文字式分類
Ia 筋紡錘（環らせん形終末） Aα
Ib ゴルジ腱器官 Aα
II 筋紡錘（散形終末）、触・圧受容器 Aβ
III 痛覚・温度覚受容器 Aδ
IV 痛覚・温度覚受容器 C

3. 運動ニューロン

α運動ニューロン

  • 細胞体が大きく、太い軸索（Aα線維）をもつ
  • 錘外筋（骨格筋）の収縮を制御
  • 脊髄前角に存在

γ運動ニューロン

  • 細胞体が小さく、細い軸索（Aγ線維）をもつ
  • 錘内筋の収縮を制御 → 筋紡錘の感度調節
α-γ連関

随意運動時、錘外筋の収縮（α運動ニューロン）と同期して錘内筋も収縮（γ運動ニューロン）→ 筋紡錘の感度を常に一定に保つ

4. 筋紡錘と腱紡錘

筋紡錘

  • 錘内筋線維とよばれる特殊な筋線維
  • 筋の伸張に応答（筋の伸張速度や筋長情報を中枢に伝える）
  • 求心性線維：Ia群線維（一次終末）、II群線維（二次終末）
  • 遠心性線維：Aγ線維（γ運動ニューロン）
  • 神経性調節で感度が変わる唯一の受容器

腱紡錘（ゴルジ腱器官）

  • 筋と腱の移行部に存在
  • 筋の張力を感知
  • 求心性線維：Ib群線維
  • 強い張力→筋収縮を抑制（自原抑制）

5. 脊髄反射

伸張反射（膝蓋腱反射など）

構成要素内容
①感覚受容器筋紡錘
②求心路Ia群線維
③反射中枢脊髄（単シナプス反射）
④遠心路α運動神経
⑤効果器伸筋（主動筋）

※下顎張反射も伸張反射の一種

屈曲反射

構成要素内容
①感覚受容器自由神経終末（侵害刺激）
②求心路Aδ線維
③反射中枢脊髄（多シナプス反射）
④遠心路α運動神経
⑤効果器屈筋（主動筋）

6. 咀嚼筋の筋紡錘

  • 閉口筋（咬筋、側頭筋、内側翼突筋）には筋紡錘が多い
  • 顎二腹筋（開口筋）には筋紡錘が少ない
  • 求心性ニューロンの細胞体は脊髄神経節（後根神経節）に存在

7. 歯髄の神経線維

  • Aδ線維：象牙質擦過刺激による鋭い痛み（一次痛）
  • C線維：鈍い痛み（二次痛）、潜時が長い
  • 感覚神経終末は自由神経終末

まとめ：覚えるべきポイント
  • Aα線維 = 運動神経 = 伝導速度最速
  • Aγ線維 = 錘内筋を収縮 = 筋紡錘の感度調節
  • Ia群線維 = 筋紡錘からの求心性線維 = 伸張反射の求心路
  • Ib群線維 = ゴルジ腱器官からの求心性線維 = 自原抑制
  • Aδ線維 = 象牙質擦過刺激の痛み = 一次痛
  • 筋紡錘が少ない筋 = 顎二腹筋（開口筋）
  • 求心性ニューロンの細胞体 = 脊髄神経節
