解剖学 / 頭頸部の脈管

頭頸部の血管

頭蓋腔へ進入する動脈

脳を栄養する動脈は内頸動脈と椎骨動脈の2つ。

動脈 経路 頭蓋内での分布
内頸動脈 頸動脈管（側頭骨）から頭蓋腔へ 眼動脈を分岐 → 大脳動脈輪
椎骨動脈 第6頸椎横突孔 → 大後頭孔から頭蓋腔へ 左右が吻合 → 脳底動脈 → 大脳動脈輪

大脳動脈輪（Willisの動脈輪）：内頸動脈系と椎骨動脈系が脳底で連絡吻合

総頸動脈の分岐

総頸動脈は甲状軟骨上縁で外頸動脈と内頸動脈に分岐する。

  • 頸動脈洞：分岐部の膨隆、動脈圧を検知
  • 頸動脈小体：分岐部に位置、血中O₂・CO₂分圧を検知
  • 頸動脈洞・頸動脈小体は舌咽神経支配

外頸動脈の8枝

分枝部位 動脈名 分布領域
前壁 上甲状腺動脈 甲状腺、喉頭前面
舌動脈 舌
顔面動脈 顔面、顎下腺（腺枝）
内壁 上行咽頭動脈 咽頭壁
後壁 後頭動脈 後頭部
後耳介動脈 耳介後部
終枝 顎動脈 側頭下隙、上下顎
浅側頭動脈 顔面部表層

舌動脈の走行

  • 舌動脈 → 舌骨上枝を分枝 → 舌深動脈と名を変え舌尖部に向かう
  • 舌背枝：舌背へ向かい上行
  • 舌下動脈：舌下隙へ分枝

顎動脈の走行（3領域）

1) 下顎枝部

  • 中硬膜動脈：棘孔から頭蓋腔へ → 脳硬膜
  • 下歯槽動脈：下顎孔から下顎管内へ → 下顎の歯・歯肉

2) 翼突部

  • 咬筋動脈、深側頭動脈、翼突筋枝、頬動脈

3) 翼口蓋部

  • 後上歯槽動脈：歯槽孔から上顎骨内へ → 上顎臼歯
  • 眼窩下動脈：眼窩下孔から → 前上歯槽動脈を分枝
  • 下行口蓋動脈：大口蓋動脈・小口蓋動脈へ
  • 蝶口蓋動脈：鼻腔粘膜

過去問

116D31

脳を栄養する血管はどれか。2つ選べ。

a 顎動脈
b 後頭動脈
c 椎骨動脈
d 内頸動脈
e 浅側頭動脈
正解：c, d

【解説】脳を栄養するのは内頸動脈（頸動脈管から頭蓋腔へ）と椎骨動脈（大後頭孔から頭蓋腔へ）。顎動脈・浅側頭動脈は外頸動脈の終枝、後頭動脈は外頸動脈の枝で頭蓋外に分布。

116A73

顎下腺の栄養動脈はどれか。1つ選べ。

a 顎動脈
b 顔面動脈
c 甲状頸動脈
d 上行咽頭動脈
e 上甲状腺動脈
正解：b

【解説】顔面動脈は顎下隙で顎下腺へ腺枝を分枝する。顎動脈は上下顎、上行咽頭動脈は咽頭壁、上甲状腺動脈は甲状腺に分布。

108A49

歯槽孔を通るのはどれか。1つ選べ。

a 顔面動脈
b 下歯槽動脈
c 浅側頭動脈
d 前上歯槽動脈
e 後上歯槽動脈
正解：e

【解説】後上歯槽動脈は歯槽孔から上顎骨内に進入し、上顎臼歯・周囲歯周組織に分布する。下歯槽動脈は下顎孔、前上歯槽動脈は眼窩下動脈から分枝。

103A78

舌で正しいのはどれか。1つ選べ。

a 有郭乳頭は舌根部にある。
b 左右の舌動脈は吻合する。
c 舌深動脈は舌尖部に向かう。
d 舌腱膜は内舌筋を左右に分ける。
e 舌体部の味覚は三叉神経が支配する。
正解：c

【解説】舌動脈は舌骨上枝を分枝した後、舌深動脈と名を変え舌尖部に向かう。有郭乳頭は分界溝の前（舌体部）、左右の舌動脈は吻合しない、舌中隔が内舌筋を左右に分ける、舌体部の味覚は顔面神経（鼓索神経）支配。
