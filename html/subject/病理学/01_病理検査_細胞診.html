細胞診

I. 組織診と細胞診の比較

組織診と細胞診の違い

組織診 細胞診
用途 確定診断 スクリーニング（場合により確定診断）
侵襲性 ある ない（少ない）
手技 経験が必要 簡便
組織構造 保持される 保持されない
情報量 多い 少ない
標本作製時間 長い 短い
一般染色 HE染色 Papanicolaou染色
細胞診の利点（組織診との比較）
  • 検体採取に伴う侵襲が少ない
  • 標本作製に要する時間が短い

II. 細胞診の手順

基本手順

① 細胞の採取 → ② 固定 → ③ 染色

固定法と染色法の対応

固定法 固定液 染色法
湿固定 95%エタノール Papanicolaou染色
乾燥固定 冷風ドライヤー、メタノール May-Giemsa染色

※ 2枚作製する場合は両方の染色を行う

III. 特殊染色

主要な特殊染色と対象

染色法 検出物 対象疾患
May-Giemsa染色 血球（細胞診） 血液塗抹標本、悪性リンパ腫、白血病
Papanicolaou染色 細胞（細胞診） 細胞診全般、角化細胞（オレンジ色）
Grocott染色 真菌 カンジダ症
PAS染色 粘液多糖、真菌 カンジダ症、腺房細胞
Ziehl-Neelsen染色 抗酸菌 結核
HE染色 一般組織 組織診の標準染色
染色法の覚え方
  • Grocott = 真菌（カンジダ）→ Grocott = 菌（Germs）
  • May-Giemsa = 血球 → 血液塗抹標本の標準
  • Papanicolaou = 細胞診 → Papスメア

IV. 口腔細胞診の判定基準

口腔細胞診報告様式ガイドライン（2015年）

分類 略称 意味 対応
NILM 陰性 悪性所見なし 経過観察
OLSIL 軽度異形成 Oral Low-grade Squamous Intraepithelial Lesion 経過観察・再検
OHSIL 高度異形成 Oral High-grade Squamous Intraepithelial Lesion 組織診へ
SCC 癌 Squamous Cell Carcinoma 組織診へ
従来のClass分類との対応
  • Class I, II → NILM（陰性）
  • Class III → OLSIL / OHSIL（異形成）
  • Class IV, V → SCC（癌疑い・癌）

※ 112A32は採点除外問題だが、ガイドライン分類の知識は重要

V. 過去問

105C76

通常の病理組織検査に比べた細胞診の利点はどれか。2つ選べ。

a 確定診断に適する。
b 検体からの情報量が多い。
c 組織構築を把握しやすい。
d 検体採取に伴う侵襲が少ない。
e 標本作製に要する時間が短い。
正解：d, e

【解説】細胞診の利点は「侵襲が少ない」「時間が短い」。a〜cは組織診の利点。

104C114

血液塗抹標本の染色法はどれか。1つ選べ。

a Sudan III染色
b Congo-Red染色
c May-Giemsa染色
d Ziehl-Neelsen染色
e hematoxylin eosin染色
正解：c

【解説】血液塗抹標本 = May-Giemsa染色。Sudan III = 脂肪、Congo-Red = アミロイド、Ziehl-Neelsen = 抗酸菌（結核）、HE = 組織診の標準。

107A123（図あり）

病理検査の顕微鏡写真（別冊No.00）を別に示す。染色法はどれか。1つ選べ。

a PAS
b Gram
c Grocott
d May-Giemsa
e Papanicolaou
正解：e

【解説】Papanicolaou染色は細胞診の標準染色。角化細胞がオレンジ色に染まるのが特徴。

113B36（図あり）

Papanicolaou 染色の細胞像（別冊No.4）を別に示す。矢印で示すものはGrocott染色に陽性を呈する。考えられるのはどれか。1つ選べ。

a Candida albicans
b Treponema pallidum
c Staphylococcus aureus
d Mycoplasma pneumoniae
e Mycobacterium tuberculosis
正解：a

【解説】Grocott染色陽性 = 真菌。選択肢の中で真菌はCandida albicansのみ。Treponema = スピロヘータ、Staphylococcus = 細菌、Mycoplasma = 細菌、Mycobacterium = 抗酸菌。
