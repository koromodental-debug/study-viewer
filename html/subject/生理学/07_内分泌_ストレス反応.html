生理学 / 内分泌

ストレス反応

I. ストレスとは

ストレスとは、外部からの刺激（ストレッサー）に対する生体の非特異的な反応のこと。ストレッサーには物理的（寒冷、外傷）、化学的（毒物）、生物学的（感染）、心理的（不安、恐怖）なものがある。

II. ストレス反応の2つの経路

ストレス反応を担う2つの系
  • 交感神経-副腎髄質系（SAM系）：即時反応（秒〜分単位）
  • 視床下部-下垂体-副腎皮質系（HPA軸）：持続的反応（分〜時間単位）

1. 交感神経-副腎髄質系（SAM系）

ストレス → 視床下部 → 交感神経興奮 → 副腎髄質 → アドレナリン・ノルアドレナリン分泌
ホルモン 主な作用
アドレナリン 心拍数増加、心収縮力増加、気管支拡張、血糖上昇（グリコーゲン分解）、代謝亢進
ノルアドレナリン 血管収縮 → 血圧上昇

この反応は「闘争か逃走か（fight or flight）」反応とも呼ばれ、危機的状況に即座に対応するための準備状態を作り出す。

2. 視床下部-下垂体-副腎皮質系（HPA軸）

ストレス → 視床下部 → CRH（副腎皮質刺激ホルモン放出ホルモン）→ 下垂体前葉 → ACTH → 副腎皮質 → コルチゾール分泌
ホルモン 主な作用
コルチゾール 血糖上昇（糖新生促進）、タンパク質異化促進、脂肪分解促進、抗炎症作用、免疫抑制

III. ストレス時のホルモン変動

分泌が増加するホルモン

ホルモン 分泌部位 ストレス反応での役割
アドレナリン 副腎髄質 即時のエネルギー動員、循環・呼吸機能亢進
ノルアドレナリン 副腎髄質、交感神経終末 血管収縮、血圧上昇
コルチゾール 副腎皮質 持続的なエネルギー供給、抗炎症作用
グルカゴン 膵臓α細胞 血糖上昇（グリコーゲン分解、糖新生）
アルドステロン 副腎皮質 Na⁺再吸収促進 → 体液量・血圧維持
バソプレシン（ADH） 視床下部→下垂体後葉 水再吸収促進 → 体液量維持、血管収縮
レニン 腎臓 アンジオテンシン-アルドステロン系活性化

分泌が低下するホルモン

ホルモン 理由
性ホルモン（エストロゲン、アンドロゲン） 生殖機能は「安静時に行われる機能」として抑制される
インスリン 血糖上昇を維持するため、インスリン分泌は抑制される
成長ホルモン（長期ストレス時） 成長・修復よりも即時のエネルギー動員が優先

IV. ストレス反応の結果

変化 機序 意義
血糖上昇（高血糖） グルカゴン↑、コルチゾール↑、アドレナリン↑、インスリン↓ エネルギー供給の確保
血圧上昇（高血圧） ノルアドレナリン（血管収縮）、アルドステロン（体液量↑） 重要臓器への血流確保
心拍数増加 アドレナリン（β₁受容体） 心拍出量増加
体液量増加 アルドステロン、バソプレシン 循環血液量の維持
免疫力低下 コルチゾール（免疫抑制作用） 過剰な炎症反応の抑制（副作用として感染しやすくなる）
消化性潰瘍 胃酸分泌亢進、胃粘液分泌低下 消化管血流の減少による粘膜防御機能低下
ストレス時に抑制される機能
  • 消化と吸収：消化管への血流減少
  • 生殖機能：性ホルモン分泌低下
  • 排泄：腎血流の一時的減少
  • 免疫機能：コルチゾールによる抑制

→ 安静時に行われている機能は抑制され、身体の活動性が高まる

V. 汎適応症候群（セリエのストレス学説）

ハンス・セリエは、ストレスに対する生体反応を3つの段階に分類した。

段階 特徴 持続時間
警告反応期 ショック相（抵抗力低下）→ 反ショック相（抵抗力回復・上昇） 数時間〜1日
抵抗期 ストレスに適応し、抵抗力が高まった状態。HPA軸の持続的活性化 数日〜数週間
疲憊期 長期ストレスにより適応能力が枯渇。副腎皮質の機能低下、免疫低下 −

VI. 過去問で確認

110C109

急性ストレス反応で血中濃度が上昇するのはどれか。2つ選べ。

a アドレナリン
b オキシトシン
c コルチゾール
d 黄体形成ホルモン
e 卵胞刺激ホルモン
正解：a, c

【解説】急性ストレス時には2つの経路が活性化される。

  • ①交感神経-副腎髄質系：アドレナリン分泌↑
  • ②視床下部-下垂体-副腎皮質系（HPA軸）：コルチゾール分泌↑

オキシトシンは射乳反射や分娩に関与。黄体形成ホルモン（LH）と卵胞刺激ホルモン（FSH）は性腺刺激ホルモンで、ストレス時にはむしろ分泌が抑制される。

VII. 歯科との関連

歯科治療とストレス

  • 歯科治療は患者にとって心理的ストレス（不安、恐怖）となりやすい
  • ストレス反応により血圧上昇、心拍数増加が起こる
  • 高血圧患者や心疾患患者では注意が必要

局所麻酔薬とアドレナリン

  • 局所麻酔薬に添加されるアドレナリンは、ストレス反応と同様の作用を示す
  • 内因性のアドレナリン分泌と合わせて作用が増強される可能性

慢性ストレスと口腔

  • コルチゾールによる免疫抑制 → 歯周病の悪化、口腔カンジダ症
  • ブラキシズム（歯ぎしり）との関連
  • 唾液分泌低下（交感神経優位）→ 口腔乾燥
