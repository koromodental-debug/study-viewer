薬理学 / 薬物動態

分布

分布とは

血管内へ移行した薬物が血管外の組織や細胞へ移行する過程をいう。

血中での存在様式（タンパク結合）

血中の薬物は血漿タンパク質と結合した状態で存在している。

  • アルブミン（66 kDa）：酸性薬物と結合
  • α1-酸性糖タンパク質（44 kDa）：塩基性薬物と結合

遊離型と結合型の違い

遊離型薬物 結合型薬物
薬効を示す 薬効がない
血管外へ移行する 血管外へ移行しない
代謝される 代謝されない
排泄される 排泄されない

肝機能障害でアルブミンが減少 → 遊離型薬物が増加 → 薬効増強

血液-組織関門

血液中の成分が透過しにくい特別な構造をもった組織。

関門の種類 特徴
血液脳関門 脳毛細血管内皮細胞の密着結合（タイトジャンクション）
血液脳脊髄液関門 脈絡叢上皮細胞
血液胎盤関門 胎盤の絨毛組織
血液精巣関門 セルトリ細胞間の密着結合
血液脳関門を通過できる薬物の特徴
  • 脂溶性が高い
  • 低分子量
  • 非イオン型

血液脳関門を通過する薬物・しない薬物

通過する 通過しない
プロポフォール（脂溶性麻酔薬） ドパミン（水溶性）
チオペンタール（脂溶性） アセチルコリン（水溶性）
レボドパ（前駆体） ノルアドレナリン（水溶性）
ネオスチグミン（第四級アンモニウム）

パーキンソン病治療：ドパミンは通過できないため、前駆体のレボドパを投与

分布容積（Vd）

薬物が溶解している理論上の容積。組織移行性の指標となる。

Vd = 投与量（X）/ 血中濃度（C）

Vdが大きい → 組織への移行性が高い（脂溶性薬物など）
Vdが小さい → 血中にとどまりやすい（水溶性薬物、タンパク結合率が高い薬物）

過去問

112A39

血液脳関門を通過するのはどれか。1つ選べ。

a アセチルコリン
b ドパミン塩酸塩
c プロポフォール
d ノルアドレナリン
e ネオスチグミンメチル硫酸塩
正解：c

【解説】血液脳関門を通過するには脂溶性が高いことが必要。プロポフォールは脂溶性の静脈麻酔薬であり、速やかに血液脳関門を通過して中枢神経に作用する。他の選択肢は水溶性またはイオン性のため通過できない。

110A56

血管から組織への薬物移行を制限する生体構造の模式図を示す。
この図が示すのはどれか。1つ選べ。

a 血液脳関門
b 血液胸腺関門
c 血液精巣関門
d 血液胎盤関門
e 血液脳脊髄液関門
正解：a

【解説】図は脳毛細血管内皮細胞がタイトジャンクション（密着結合）で連結している構造を示しており、血液脳関門の特徴である。この構造により、水溶性物質や高分子の脳への移行が制限される。

114C90（計算問題）

ある薬物120mgを静脈内注射したところ、3時間後の血漿中薬物濃度は1.2μg/mLであった。
この薬物の分布容積（L）を求めよ。
ただし、この薬物の生物学的半減期は3時間で、分布は1コンパートメントモデルに従うものとする。

正解：50

Step 1：3時間後 = 半減期1回分 → 濃度は初期の1/2に低下

Step 2：初期濃度 = 1.2 × 2 = 2.4 μg/mL

Step 3：Vd = 投与量 / 初期濃度
= 120 mg / 2.4 μg/mL
= 120,000 μg / 2.4 μg/mL
= 50,000 mL = 50 L
