POS（問題志向型システム）

POSとは

POS（Problem Oriented System）は、問題志向型システムのこと。

診察から治療計画立案までを系統的に行う診療記録システム。

関連用語

略語 正式名称 意味
POS Problem Oriented System 問題志向型システム
POMR Problem Oriented Medical Record 問題志向型診療録

SOAP形式（超頻出）

POMRで用いられる記録形式。患者の問題ごとに記載する。

SOAPの4要素
  • S（Subjective）：主観的情報 = 患者の訴え、自覚症状
  • O（Objective）：客観的情報 = 他覚所見、検査結果
  • A（Assessment）：評価 = 診断、鑑別診断
  • P（Plan）：計画 = 治療計画

SOAPの具体例

項目 該当するもの 該当しないもの
S 患者の訴え、脱離時期、痛みの訴え 検査所見、他覚所見
O 視診所見、検査結果、モニタ情報、他覚所見 患者の訴え、治療計画
A 鑑別診断、診断名 検査所見、治療計画
P 治療計画、処方、指導計画 検査所見、診断

「O」の判断ポイント

「O」は医療者が客観的に得た情報。

  • 視診で齲窩が認められる → O
  • 生体監視モニタ情報 → O
  • エックス線所見 → O
  • 2日前に冷水痛があった → S（患者の訴え）

過去問

115A34

診察から治療計画立案までを系統的に行うのはどれか。1つ選べ。

a DNR〈Do Not Resuscitate〉
b DOS〈Disease Oriented System〉
c EBM〈Evidence Based Medicine〉
d NBM〈Narrative Based Medicine〉
e POS〈Problem Oriented System〉
正解：e

【解説】POS（問題志向型システム）は診察から治療計画立案までを系統的に行う。EBMは根拠に基づく医療、NBMは物語に基づく医療。

117D13

問題解決指向型診療録作成に用いられるSOAPの「O」に該当するのはどれか。1つ選べ。

a 主訴
b 感染源の推定
c 処方する薬剤
d 予定手術術式
e 生体監視モニタ情報
正解：e

【解説】「O」は客観的情報（他覚所見、検査結果）。生体監視モニタ情報は客観的データ。主訴はS、処方や手術術式はP。

113C20

上顎右側臼歯部の疼痛を主訴とする患者の診療録記載内容のうち、SOAPの「O」にあたるのはどれか。1つ選べ。

a 2日前に冷水痛があった。
b 視診で齲窩が認められる。
c コンポジットレジン修復をする。
d 審美的な歯科治療を希望している。
e これまで歯科治療を受けたことがある。
正解：b

【解説】視診所見は「O」（客観的情報）。冷水痛の訴えや希望はS、修復計画はP。

111B11

問題解決指向型診療録におけるSOAPの「A」にあたる事項はどれか。1つ選べ。

a 鑑別診断
b 検査所見
c 指導計画
d 治療結果
e 治療方針
正解：a

【解説】「A」は評価（Assessment）＝鑑別診断。検査所見はO、指導計画・治療方針はP。

109A31

修復物の脱離を主訴とする患者に対し、診察と検査後に再装着処置を行った。この診療記録をSOAPに準拠して作成する場合、「S」に該当するのはどれか。1つ選べ。

a 窩洞形態
b 治療方針
c 脱離時期
d 再装着処置
e エックス線所見
正解：c

【解説】「S」は主観的情報＝患者の訴え。脱離時期は患者から聴取する情報。窩洞形態・エックス線所見はO、治療方針・処置はP。
