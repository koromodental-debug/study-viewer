組織診

I. 組織診の手順

1. 組織採取 → 2. 固定 → 3. 脱灰* → 4. 切り出し → 5. 脱水 → 6. 包埋 → 7. 薄切 → 8. HE染色

* 脱灰は硬組織（骨・歯）を含む場合のみ

各手順の詳細

手順 目的・方法 使用薬剤
固定 組織の自己融解を防止、構造を安定化 10〜20%ホルマリン
脱灰 硬組織（骨・歯）のCaを除去 ギ酸、塩酸、EDTA
脱水 組織中の水分を除去 エタノール系列
包埋 薄切可能な硬さにする パラフィン
薄切 顕微鏡観察できる厚さに切る 厚さ：約4μm
染色 組織構造を可視化 HE染色（標準）

II. HE染色

ヘマトキシリン・エオジン染色

染色液 性質 染まる構造 色
ヘマトキシリン 塩基性色素 核（DNA/RNA）、軟骨基質 青紫色
エオジン 酸性色素 細胞質、膠原線維、赤血球 赤〜ピンク色
HE染色の覚え方
  • Hematoxylin = 核 = 青紫（Hは「濃い」→ 核）
  • Eosin = 細胞質 = ピンク（Eは「淡い」→ 細胞質）

III. 生検の種類

種類 方法 特徴
切除生検 病変全体を切除 小さな病変向け、診断と治療を兼ねる
切開生検
（部分生検）		 病変の一部を切除 確定診断に最適、大きな病変向け
パンチ生検 円筒形に採取 皮膚・粘膜病変向け
針生検 太い針で採取 深部病変向け
口唇腺生検 下口唇小唾液腺を採取 Sjogren症候群の診断
Sjogren症候群の口唇腺生検
  • 診断基準：4mm2あたり50個以上の単核球（リンパ球）浸潤
  • 1 focus = 50個以上の単核球集簇
  • focus score ≧1 で陽性

IV. 過去問

108C5

生検組織の固定液はどれか。1つ選べ。

a キシレン
b クエン酸水溶液
c ジエチルエーテル
d 塩化カルシウム水溶液
e ホルムアルデヒド水溶液
正解：e

【解説】生検組織の固定液 = ホルムアルデヒド（ホルマリン）。キシレン = 透徹・脱パラフィン、ジエチルエーテル = 麻酔薬（歴史的）。

107A114

Sjogren症候群における口唇腺生検での単核球浸潤の診断指標はどれか。1つ選べ。

a 赤血球
b 好中球
c 好酸球
d 好塩基球
e リンパ球
正解：e

【解説】Sjogren症候群ではリンパ球（単核球）の浸潤が特徴。4mm2あたり50個以上で陽性。

109C2

Papanicolaou染色の固定液はどれか。1つ選べ。

a エチレン
b キシレン
c トルエン
d エタノール
e フェノール
正解：d

【解説】Papanicolaou染色（細胞診）= 95%エタノールで湿固定。組織診のホルマリン固定と区別すること。
