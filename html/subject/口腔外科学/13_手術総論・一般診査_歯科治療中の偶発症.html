歯科治療中の偶発症

歯科治療中に発生する偶発症は、全身的偶発症と局所的偶発症に大別される。全身的偶発症のうち最も頻度が高いのは血管迷走神経反射（約60%）である。

全身的偶発症

1. 血管迷走神経反射（神経原性ショック）

歯科治療中の全身的偶発症で最も頻度が高い（約60%）。デンタルショックとも呼ばれる。

  • 原因：不安・恐怖・疼痛などの精神的ストレス → 交感神経の過緊張 → 反動で迷走神経が過剰に亢進
  • 症状：顔面蒼白、冷汗、悪心、心拍出量減少、血圧低下、徐脈、意識消失
  • 対処：水平位＋下肢挙上（ショック体位）、酸素投与（10L/分）、改善なければ硫酸アトロピン0.5mg投与

※一過性であり、体位変換で速やかに改善することが多い

2. 局所麻酔薬中毒

局所麻酔薬の過量投与や血管内誤注入により血中濃度が急上昇して発症する。

  • 中枢興奮期（初期）：不安、興奮、多弁、振戦 → 全身痙攣
  • 中枢抑制期（進行）：意識消失 → 呼吸抑制 → 心停止
  • 対処：気道確保、酸素投与、痙攣に対しジアゼパム静注
  • 予防：注入前の吸引テスト（血液逆流の確認）、少量ずつ緩徐に注入

3. アナフィラキシーショック

局所麻酔薬や添加物に対するI型アレルギー反応。エステル型（プロカイン等）に多く、アミド型（リドカイン）では稀。

  • 症状：皮膚の発赤・蕁麻疹、喉頭浮腫による呼吸困難、血圧低下、頻脈
  • 対処：アドレナリン（エピネフリン）0.3mg筋注（大腿外側）、気道確保、酸素投与、救急要請

4. 過換気症候群

不安や恐怖による過呼吸で血中CO2が過度に排出され、呼吸性アルカローシスを生じる。女性・若年者に多い。

  • 症状：息苦しさ、四肢・口唇のしびれ、テタニー（手指の硬直・助産師手位）、めまい
  • 対処：声かけで落ち着かせ、ゆっくり呼吸させる（息ごらえ）、酸素投与
  • ペーパーバッグ法は低酸素のリスクがあり、現在は推奨されない

口底出血と上気道閉塞

下顎前歯部〜小臼歯部の手術（インプラント埋入、抜歯など）で舌側の骨を穿孔すると、舌下動脈やオトガイ下動脈を損傷する危険がある。

口底出血→上気道閉塞のメカニズム
  • 下顎舌側の血管損傷 → 口底（舌下隙・顎下隙）に血腫形成
  • 血腫が増大 → 舌が挙上される
  • 舌の挙上 → 上気道閉塞 → 窒息

抗血栓療法中の患者では出血リスクが増大し、術後の血腫形成が急速に進行する。早期の止血処置が生命予後を左右する。

対応

  • 止血処置を速やかに行う（出血源の結紮・圧迫止血）
  • 気道確保（必要に応じて気管挿管・気管切開）
  • バイタルサインのモニタリング

誤飲・誤嚥

歯科治療中にクラウン・インレー・小器具などが口腔内に落下し、患者が飲み込むことがある。

誤飲（消化管）誤嚥（気道）
経路食道 → 胃 → 腸管気管 → 気管支
症状多くは無症状咳嗽、呼吸困難、チアノーゼ
確認腹部エックス線撮影胸部エックス線撮影
対応多くは自然排出。鋭利な異物は内視鏡で摘出緊急対応：気管支鏡で摘出

予防

  • ラバーダムの使用（特に歯内療法時）
  • ガーゼスクリーン（咽頭部にガーゼを置く）
  • 小器具へのフロスタイ（脱落防止の糸）

過去問で確認

114A64

58歳の女性。舌の腫脹を主訴として来院した。昨日、他院で下顎前歯部にインプラントを埋入し、今朝から舌の腫れを自覚しているという。8年前に心筋梗塞を発症し、現在も抗血栓療法を受けている。診察の結果、止血処置を行うこととした。処置前の口腔内写真（別冊No. 24）を別に示す。
止血処置により発症が回避できるのはどれか。1つ選べ。

a 気　胸
b 昏　睡
c 肺塞栓
d 上気道閉塞
e アナフィラキシーショック
正解：d

【解説】下顎前歯部のインプラント埋入後、抗血栓療法中の患者に舌の腫脹が出現している。口底への出血が貯留し、舌が挙上されている状態である。この出血が進行すると舌がさらに挙上され、上気道閉塞（d）を引き起こす危険がある。止血処置により口底出血を制御することで、上気道閉塞の発症を回避できる。気胸（a）、昏睡（b）、肺塞栓（c）、アナフィラキシーショック（e）は口底出血とは直接関連しない。
