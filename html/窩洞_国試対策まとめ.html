5. 2級メタルインレー窩洞

基本的保持形態

  • 箱型（隣接面窩洞）
  • 外開き形態（咬合面窩洞）
保持形態の分類（保存修復学21 第五版 p.114-115）
分類 形態
基本的保持形態 ①箱形（box form）
②内開き形（undercut form）
③外開き形（tapered form）
補助的保持形態 ①階段（step）
②鳩尾形（dovetail form）
③溝（channel）
④穿下（undercut）
なぜ「鳩尾形」ではなく「外開き形態」？（正答率27.5%）

問題文は「基本的保持形態」を問うている。

  • 外開き形：基本的保持形態 → 正解
  • 鳩尾形：補助的保持形態 → 不正解
教科書の記載（p.115）

外開き形：「インレー修復の場合、インレー体を窩洞内に装着するため外開きを与える。しかし、あまり外開きの程度を強くすると保持力は失われる。」

鳩尾形：「修復物の側方脱出力に抵抗する水平拘止効力である。」

窩洞形成の原則

  • 予防拡大：自浄域まで拡大
  • 咬頭隆線の保存：可能な限り保存
  • 凸隅角部の曲面化：応力集中防止
  • 遊離エナメル質の除去：破折防止

6. GIC修復窩洞の特徴

  • 窩縁形態：バットジョイント
  • 予防拡大：不要（接着性修復）
  • アンダーカット：不要
  • 便宜形態：口蓋側への開放
  • 歯面処理：ポリアクリル酸（10〜20秒）
  • 齲蝕検知液：アシッドレッド

7. CR修復のポイント

ベベル付与の目的（前歯部）

  • 接着面積の増大
  • 窩縁部亀裂の防止
  • 色調適合性の向上

窩洞形成で配慮する事項

  • 円滑な曲線の付与
  • コントラクションギャップの防止

9. 試験対策ポイント

必ず覚えるポイント
  • 12級メタルインレーの保持形態 = 箱型 + 外開き形態
  • 2メタルインレー窩洞形成 = 予防拡大 + 咬頭隆線保存 + 凸隅角曲面化
  • 3セラミック/CRインレー = バットジョイント + 線角部曲面化 + 大テーパー
  • 4GIC修復 = バットジョイント + 便宜形態（口蓋側開放） + ポリアクリル酸処理
  • 5齲蝕検知液 = アシッドレッド（フクシンではない）
  • 6CR修復ベベルの目的 = 接着面積増大 + 窩縁亀裂防止 + 色調適合性向上
  • 7CR窩洞形成の配慮 = 円滑な曲線の付与
  • 8遊離エナメル質は除去する（保存ではない）
  • 9積層充填 = コントラクションギャップの防止
