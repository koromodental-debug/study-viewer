3. ワルファリンの重要ポイント

ワルファリンの特徴
  • 作用発現: 24〜48時間（遅い）
  • モニタリング: PT-INRで管理
  • ビタミンK含有食品（納豆）禁忌
ワルファリンとNSAIDsの相互作用

NSAIDsのアルブミン結合性 ＞ ワルファリンの結合性

→ ワルファリンがアルブミンから遊離

→ 活性型（遊離型）が増加

→ 出血しやすくなる

ワルファリン作用を増強する薬物
  • ミコナゾール（抗真菌薬）- CYP2C9阻害
  • NSAIDs - 血漿タンパク結合競合
  • メトロニダゾール

※カルバマゼピン、リファンピシン → 作用減弱

4. DOAC vs ワルファリン

項目 ワルファリン DOAC
作用機序 ビタミンK拮抗（間接的） 凝固因子を直接阻害
効果発現 24〜48時間 速い（数時間）
モニタリング 必要（PT-INR） 不要
食事制限 必要（納豆等禁忌） 不要
抜歯時 PT-INR確認 休薬せず抜歯

8. 試験対策ポイント

必ず覚えるポイント
  • 1トロンビン = 唯一血液凝固系に直接作用する局所止血薬
  • 2骨からの出血 → 挫滅法（永久的）、栓塞法（抜歯窩）
  • 3アスピリン = シクロオキシゲナーゼ阻害（血小板凝集抑制）
  • 4チクロピジン = ADP受容体拮抗
  • 5ヘパリン = アンチトロンビンIII増強 → Xa因子阻害
  • 6ワルファリン = ビタミンK拮抗（納豆禁忌）
  • 7ミコナゾールでワルファリン作用増強
  • 8DOAC抜歯 = 休薬せず + 縫合 + 局所止血
  • 9PT正常・APTT延長 → 血友病
  • 10再生不良性貧血の出血傾向 = 血小板減少
