組織学 / 03_歯

歯の構造と発生

1. エナメル質

体表外胚葉（エナメル器）由来。生体で最も硬い組織。

エナメル質の特徴

  • モース硬度6〜7（水晶程度）
  • 組成の95%以上が無機質（ハイドロキシアパタイト）
  • 熱・電気の不良導体
  • 血管・神経を含まない
  • 再生能がない

エナメル質の構造物

構造特徴脱灰標本で
エナメル小柱横断面は鍵穴型、4つのエナメル芽細胞で形成消失
横紋4μm間隔、サーカディアンリズムを反映消失
Retzius線条7〜10日に1本形成、表面で周波条に消失
周波条Retzius線が表面に達した部分消失
Schreger線条エナメル小柱の走行による縞模様消失
エナメル叢低石灰化部、有機質が残存残存
エナメル葉象牙境から表面に至る有機質残存
脱灰標本で消失 vs 残存
  • 消失：無機質（石灰化）に依存する構造 → 横紋、Retzius線、周波条、Schreger線条
  • 残存：有機質が残存する構造 → エナメル叢、エナメル葉
116D21

歯の脱灰H-E染色組織標本の作製過程で消失するのはどれか。3つ選べ。

a 周波条
b Retzius条
c 球間象牙質
d Andresen線
e Schreger線条
正解：a, b, e

【解説】脱灰により無機質が除去されるため、石灰化に依存する構造（周波条、Retzius条、Schreger線条）は消失。球間象牙質とAndresen線は象牙質の構造で、有機質（コラーゲン）が残るため消失しない。

115D81

エナメル質石灰化において有機質の残存により生じるのはどれか。2つ選べ。

a エナメル叢
b エナメル葉
c Retzius線条
d Schreger線条
e エナメル小柱の横紋
正解：a, b

【解説】エナメル叢とエナメル葉は低石灰化部であり、有機質が残存している。Retzius線条、Schreger線条、横紋は石灰化の程度に関連する構造。

歯の組織像（縦断研磨切片、カルボールフクシン染色）（別冊No.33）を別に示す。矢印で示す構造はどれか。1つ選べ。

a Andresen線条
b Nasmyth膜
c Owen外形線
d Retzius線条
e Schreger線条
正解：d

【解説】エナメル象牙境から表面に向かって斜めに走る線はRetzius線条。エナメル質形成が低下した部分を反映し、7〜10日に1本形成される。

2. エナメル芽細胞

エナメル質を形成する細胞。内エナメル上皮から分化する。

エナメル芽細胞の分化段階と機能

段階主な機能
形成期アメロゲニンの分泌、エナメル基質の形成
移行期形成期から成熟期への移行
成熟期アメロゲニンの脱却（除去）、Ca²⁺の供給、石灰化促進
退縮期萌出前の保護（Nasmyth膜形成）
114C79

エナメル芽細胞の機能で正しいのはどれか。3つ選べ。

a 基質小胞の分泌
b アメロゲニンの脱却
c アメロゲニンの分泌
d コラーゲン線維の分泌
e カルシウムイオンの供給
正解：b, c, e

【解説】エナメル芽細胞は形成期にアメロゲニンを分泌し、成熟期にアメロゲニンを脱却してCa²⁺を供給する。基質小胞は骨芽細胞や軟骨細胞が分泌。コラーゲンはエナメル質に含まれない。

109A40

エナメル基質を脱却するのはどれか。1つ選べ。

a 前エナメル芽細胞
b 形成期エナメル芽細胞
c 移行期エナメル芽細胞
d 成熟期エナメル芽細胞
e 退縮エナメル上皮
正解：d

【解説】成熟期エナメル芽細胞がアメロゲニン（エナメル基質の主成分）を脱却（除去）し、石灰化を促進する。

3. 歯胚の発生

歯は上皮間葉相互作用（epithelial-mesenchymal interaction）により発生する。

歯胚の由来

由来構造形成組織
上皮
（外胚葉）		口腔粘膜上皮→歯堤→エナメル器エナメル質
唇溝堤→口腔前庭−
間葉
（神経堤由来）		歯乳頭象牙質、歯髄
歯小嚢セメント質、歯根膜
固有歯槽骨

歯胚の発生段階

時期特徴分化の指標
蕾状期
(bud stage)		歯堤から上皮が伸び出し、周囲に間葉細胞が集積歯胚形成開始
帽状期
(cap stage)		エナメル器、歯乳頭、歯小嚢に分化歯乳頭・歯小嚢の出現
鐘状期
(bell stage)		エナメル器が鐘状に、硬組織形成開始エナメル質・象牙質形成
エナメル器の構成（帽状期〜鐘状期）
  • 外エナメル上皮：エナメル器の外層
  • エナメル髄（星状網）：エナメル器中央の細胞
  • 中間層：内エナメル上皮の外側
  • 内エナメル上皮：→エナメル芽細胞に分化

硬組織形成の順序

  • 象牙質がエナメル質に先行して形成開始
  • 象牙質：切縁・咬頭頂部のエナメル象牙境から開始し、歯髄側に向かって進行
  • エナメル質：象牙質に遅れて開始し、表面に向かって進行

歯根の形成

  • Hertwig上皮鞘：内エナメル上皮＋外エナメル上皮で構成
  • 歯根象牙質形成を誘導後、セメント質形成とともに断裂
  • 断裂した上皮はMalassez上皮遺残として歯根膜に残存
113A68

歯の発生において間葉から分化するのはどれか。2つ選べ。

a エナメル質
b 象牙質
c セメント質
d 歯根膜
e Hertwig上皮鞘
正解：b, c（またはb, d）

【解説】間葉（神経堤由来）から分化するのは歯乳頭由来の象牙質・歯髄と、歯小嚢由来のセメント質・歯根膜・固有歯槽骨。エナメル質は外胚葉（上皮）由来、Hertwig上皮鞘も上皮由来。

110C56

歯胚の帽状期にみられるのはどれか。2つ選べ。

a 歯乳頭
b 歯小嚢
c エナメル芽細胞
d 象牙芽細胞
e Hertwig上皮鞘
正解：a, b

【解説】帽状期でエナメル器、歯乳頭、歯小嚢が出現する。エナメル芽細胞と象牙芽細胞は鐘状期に分化。Hertwig上皮鞘は歯根形成期。

4. 歯髄

歯髄腔を満たす結合組織。神経堤由来（頭部外胚葉性間葉）。

歯髄の機能

  • 象牙質の形成（象牙芽細胞による）
  • 侵害刺激の感受（知覚神経が分布）
  • 栄養供給（血管が豊富）
  • 防御機能（免疫細胞、第三象牙質形成）
105C99

歯髄の機能で正しいのはどれか。2つ選べ。

a 象牙質の形成
b 咬合圧の感受
c 侵害刺激の感受
d エナメル質の修復
e セメント質の誘導
正解：a, c

【解説】歯髄は象牙質の形成と侵害刺激（痛み）の感受を担う。咬合圧の感受は歯根膜の機能。エナメル質は再生能がない。セメント質の誘導は歯根膜（セメント芽細胞）の機能。
