止血機構

1. 止血の流れ

止血は一次止血と二次止血の2段階で進行する:

段階 主役 機序
一次止血 血小板 血管損傷部位に血小板が粘着・凝集して血小板血栓を形成
二次止血 凝固因子 凝固カスケードによりフィブリンが形成され、血栓を強化

2. 凝固因子一覧

番号 名称 作用
I フィブリノゲン フィブリンの前駆体
II プロトロンビン トロンビンの前駆体
III 組織因子（TF） 外因系の開始因子
V プロアクセレリン Xaと結合しプロトロンビンを活性化
VII プロコンベルチン IIIと結合しXを活性化（外因系）
VIII 抗血友病A因子 Xを活性化（血友病Aで欠乏）
IX 抗血友病B因子 VIIIと共にXを活性化（血友病Bで欠乏）
X スチュアート因子 プロトロンビンを活性化（共通経路）
XI PTA IXを活性化（内因系）
XII ハーゲマン因子 接触活性化で凝固開始（内因系）
XIII フィブリン安定化因子 フィブリンを架橋し安定化
― von Willebrand因子 血小板粘着、VIIIの安定化
ビタミンK依存性凝固因子

II, VII, IX, X（覚え方: 肉納豆＝2, 9, 7, 10）

→ ビタミンK欠乏やワルファリン投与でPT延長

3. 凝固カスケード

血液凝固には内因系と外因系があり、最終的に共通系に合流する:

経路 開始因子 関与する因子 検査
内因系 血管内皮の損傷
コラーゲンの露出		 XII→XI→IX→VIII APTT
外因系 組織因子（TF）
組織の損傷		 VII PT
共通系 内・外因系の合流 X→V→II（トロンビン）→I（フィブリン） PT, APTT両方

外因系は通常10〜14秒で完了（PTで評価）。内因系は血管内皮傷害から開始。

4. 出血性素因の分類

分類 先天性 後天性
血管壁の異常 Osler病、Ehlers-Danlos症候群、Marfan症候群 老人性紫斑病、アレルギー性紫斑病、壊血病
血小板の異常 ― ITP、TTP、薬剤性、再生不良性貧血
凝固因子の異常 血友病A・B、von Willebrand病 ビタミンK欠乏、肝疾患
線溶系の異常 α2-プラスミンインヒビター欠乏 DIC

5. 検査と疾患の関係

出血時間

Duke法: 耳朶をランセットで穿刺、出血が止まるまでの時間（基準値2〜5分）

→ 一次止血（血小板機能）を評価

PT（プロトロンビン時間）

項目 内容
評価対象 外因系と共通系（基準値11〜16秒）
PT延長 肝硬変、ビタミンK欠乏、ワルファリン服用、DIC
PT-INR ワルファリン療法のモニタリング（WHO標準化）

APTT（活性化部分トロンボプラスチン時間）

項目 内容
評価対象 内因系と共通系（基準値30〜40秒）
APTT延長 血友病A・B、von Willebrand病、ヘパリン投与
検査所見からの鑑別
  • PT正常・APTT延長 → 血友病、von Willebrand病
  • PT延長・APTT正常 → 第VII因子欠乏、ワルファリン初期
  • PT延長・APTT延長 → 肝硬変、ビタミンK欠乏、DIC
  • 出血時間延長・PT/APTT正常 → 血小板異常

6. 出血性疾患

血友病A・B

項目 血友病A 血友病B
欠乏因子 第VIII因子 第IX因子
遺伝形式 X連鎖劣性（潜性）遺伝→ 男性に発症
頻度 男子3,875名に1人 男子851名に4名
検査 PT正常、APTT延長
症状 関節内出血、筋肉内出血、抜歯後の遷延出血
治療 凝固因子製剤の補充療法
歯科における血友病への対応
  • 抜歯前に補充療法で凝固因子活性を上昇させる
  • 局所止血に加え、止血シーネなどを装着して創面保護
  • 軽症〜中等度: 局所の血のみで対応可能な場合も

von Willebrand病

項目 内容
原因 von Willebrand因子の欠乏・異常
機能 血小板の粘着に関与、第VIII因子の安定化
検査 出血時間延長、APTT延長

特発性血小板減少性紫斑病（ITP）

項目 内容
原因 抗血小板抗体による血小板の破壊亢進
急性ITP 小児（2〜6歳）、ウイルス感染後、自然軽快多い
慢性ITP 成人女性に多い、H. pylori関連あり（除菌で改善）
検査 血小板数減少（5万/μL以下）、PT・APTT正常
症状 点状出血、紫斑、歯肉出血
治療 ステロイド、γ-グロブリン大量療法

7. 抗凝固薬と歯科治療

ワルファリン

項目 内容
作用機序 ビタミンK拮抗→凝固因子（II, VII, IX, X）の合成阻害
モニタリング PT-INR（通常2.0〜3.0でコントロール）
抜歯時 PT-INR確認、原則休薬せず抜歯
相互作用 ミコナゾール→作用増強

DOAC（直接経口抗凝固薬）

項目 内容
特徴 PT-INRでのモニタリング不要
抜歯時 原則休薬せず抜歯、抜歯創を縫合

8. 関連過去問

112C-44

プロトロンビン時間は正常であるが、活性化部分トロンボプラスチン時間が延長したときに疑われる疾患はどれか。1つ選べ。

a: 肝硬変　b: 血友病　c: 肺血栓塞栓症　d: 再生不良性貧血　e: 特発性血小板減少性紫斑病

正解: b（血友病）

※PT正常・APTT延長＝内因系の異常＝血友病

116A-13

血友病Aはどれか。1つ選べ。

a: 常染色体異常　b: 性染色体異常　c: X連鎖劣性〈潜性〉遺伝病　d: 常染色体優性〈顕性〉遺伝病　e: 常染色体劣性〈潜性〉遺伝病

正解: c（X連鎖劣性遺伝病）

118D-80

直接経口抗凝固薬〈DOAC〉服用患者の抜歯で適切なのはどれか。2つ選べ。

a: 抜歯創を縫合する　b: 永久的止血法を行う　c: 抜歯前にPT-INRを測定する　d: 原則として休薬せずに抜歯する　e: 抜歯前にステロイドカバーをする

正解: a, d

※DOAC→PT-INR不要、休薬せず、縫合する

116B-19

血栓形成の原因はどれか。1つ選べ。

a: 線溶の亢進　b: 血小板数の減少　c: 血液粘稠度の低下　d: 血液凝固因子の減少　e: 血管内皮細胞の傷害

正解: e（血管内皮細胞の傷害）

※Virchowの3徴: 血流停滞、血管内皮傷害、血液凝固能亢進
